📊 Estructura de Evaluaciones

El curso consta de 6 evaluaciones con una distribución del 100% de la nota final. Cada evaluación está alineada con un resultado de aprendizaje específico del sistema PANDORA.

Eval % Tipo Tema Fecha Resultado de Aprendizaje
E1 15% Taller Estructura y Tipos de SO 25/02/2026 Identifica la estructura y los tipos de los sistemas operativos
E2 15% Informe Gestión de Procesos 11/03/2026 Gestiona los procesos que se llevan a cabo en los sistemas operativos
E3 20% Examen Memoria, E/S, Archivos 25/03/2026 Administra la memoria, los procesos de entrada y salida, el sistema de archivos...
E4 15% Reporte Seguridad en SO 22/04/2026 Evalúa la seguridad de los sistemas operativos
E5 15% Proyecto Fase 4: Servidores Web y Monitoreo 06/05/2026 comprende la funcionalidad de conceptos fundamentales de la materia...
E6 20% Proyecto Fase 5: Entrega Final + Sustentación 27/05/2026 Estudia las interfaces que ofrece el Sistema Operativo al usuario...

📌 Información Importante

  • Las evaluaciones E3 y E6 son exámenes con énfasis en análisis de escenarios (no memorización)
  • Las evaluaciones E1, E2, E4 y E5 son trabajos prácticos con sustentación obligatoria
  • Todas las evaluaciones incluyen componente teórico (40%) y práctico (60%)
  • La suma total de porcentajes es 100%

🎯 Metodología del Curso

Distribución Teórico-Práctica

Tipo de Evaluación Teoría Práctica Evaluaciones
Trabajos (E1, E2, E4, E5) 40% 60% Taller, Informe, Reporte
Exámenes (E3, E6) 60% 40% Examen Parcial, Examen Final

💻 Componente Práctico

  • Scripts: Bash (Linux) y PowerShell (Windows)
  • Comandos reales: Ejecución en entornos Linux y Windows
  • Evidencias: Capturas de pantalla de configuraciones
  • Configuraciones prácticas: Servidores, permisos, monitoreo

🧠 Enfoque: Sin Exámenes de Memorización

  • Análisis de escenarios: Resolver situaciones reales
  • Resolución de problemas: Aplicar conocimiento práctico
  • Desarrollo de soluciones: Crear scripts y configuraciones
  • Sustentación: Defensa oral de trabajos

📚 Contenido por Evaluación

E1 - Estructura y Tipos de SO (15%)

  • Definición y funciones del SO
  • Tipos: monolítico, microkernel, híbrido
  • Estructura: kernel, shell, utilidades
  • Evolución histórica de los SO
  • Comparación Linux vs Windows vs macOS

E2 - Gestión de Procesos (15%)

  • Concepto de proceso y estados
  • PCB (Process Control Block)
  • Cambio de contexto
  • Comandos: ps, top, kill, nice
  • Scripts de monitoreo

E3 - Examen Parcial (20%)

  • Gestión de memoria: paginación, segmentación
  • Memoria virtual y swap
  • Entrada/Salida y DMA
  • Sistemas de archivos (introducción)
  • Sincronización: semáforos, mutex, deadlock

E4 - Seguridad en SO (15%)

  • Mecanismos: SELinux, AppArmor, UAC
  • Control de acceso: DAC, MAC, RBAC
  • Permisos avanzados: SUID, SGID, ACLs
  • Hardening y auditoría de sistemas
  • Matriz de riesgos de seguridad

E5 - Conceptos Fundamentales (15%)

  • Evaluación integradora
  • Sistema de archivos: EXT4, NTFS, inodos
  • Procesos e hilos: gestión avanzada
  • Memoria: administración y tuning
  • Scripts integrales de todo el curso

E6 - Examen Final (20%)

  • Todo el contenido del curso
  • Énfasis en interfaces: CLI, GUI, APIs
  • Análisis de escenarios prácticos
  • Configuración de servicios web
  • Hardening básico de sistemas
