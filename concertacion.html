📊 Estructura de Evaluaciones

El curso consta de 6 evaluaciones con una distribución del 100% de la nota final. Cada evaluación está alineada con un resultado de aprendizaje específico del sistema PANDORA.

Eval % Tipo Tema Fecha Resultado de Aprendizaje
E1 15% Informe Fundamentos y Arquitectura del SO 25/02/2026 Fase 1: Configuración inicial del proyecto (identifica estructura y tipos de SO)
E2 15% Software Gestión de Procesos y Servicios 11/03/2026 Fase 2: Monitoreo y control de procesos (gestiona procesos en SO)
E3 20% Laboratorio Memoria, E/S y Sistemas de Archivos 25/03/2026 Laboratorio individual: 5 escenarios de optimización (administra memoria, E/S, archivos, sincronización)
E4 15% Software Seguridad y Hardening 22/04/2026 Fase 4: Aseguramiento del sistema (evalúa seguridad de SO)
E5 15% Software Integración de Servicios 06/05/2026 Fase 5: Servidores web funcionando (comprende conceptos fundamentales integrados)
E6 20% Presentación Sustentación Final 27/05/2026 Fase 6: Sistema completo + Sustentación en vivo (estudia interfaces del SO: web, CLI, API)

📌 Modelo de Evaluación: Proyecto Incremental de 6 Fases

Este curso implementa un proyecto incremental de 6 fases donde cada evaluación (E1-E6) corresponde a una fase de avance del proyecto final. Las notas se acumulan progresivamente hasta completar el 100%.

  • Fase 1 (E1): 15% - Fundamentos - Configuración inicial del proyecto
  • Fase 2 (E2): 15% - Procesos - Monitoreo y control de procesos
  • Fase 3 (E3): 20% - Laboratorio Individual - 5 escenarios prácticos de Memoria, E/S, Sincronización y Sist. Archivos básico (hasta C12)
  • Fase 4 (E4): 15% - Seguridad - Aseguramiento del sistema
  • Fase 5 (E5): 15% - Integración - Servidores web funcionando (incluye Sist. Archivos avanzado de C13)
  • Fase 6 (E6): 20% - Sustentación Final - Sistema completo + Sustentación en vivo
  • Todas las fases incluyen componente práctico obligatorio
  • Cada fase construye sobre la anterior, acumulando el proyecto final
  • Ver la 📘 Guía del Proyecto para detalles de cada fase

⚠️ Nota Importante sobre la Estructura del Curso

Fase 3 (Checkpoint E3) vs Fase 5 (Integración E5):

  • E3 (25/03): Checkpoint práctico que evalúa contenido hasta Clase 12 (Sistemas de Archivos introductorio). Temas: Memoria, E/S, Sincronización, Procesos, y Sist. Archivos básico (inodos, permisos).
  • E5 (06/05): Proyecto integrador que incluye temas avanzados de Clase 13 (journaling, RAID, fstab) junto con integración de servicios.

Esta distribución permite que el checkpoint E3 verifique comprensión antes de Semana Santa, mientras que los temas avanzados de sistemas de archivos se integran en el proyecto final con aplicación práctica real.

📚 Contenido por Evaluación

FASE 1 (E1): Fundamentos y Arquitectura del SO - 15%

  • Fase 1 del Proyecto: Configuración inicial del entorno
  • Definición y funciones del SO aplicadas al proyecto
  • Arquitecturas: monolítico, microkernel, híbrido
  • Estructura: kernel, shell, utilidades
  • Comparación Linux vs Windows vs macOS para el proyecto
  • Instalación y configuración de VM con Ubuntu Server
  • Esta fase establece las bases del proyecto final

FASE 2 (E2): Gestión de Procesos y Servicios - 15%

  • Fase 2 del Proyecto: Monitoreo y control de procesos
  • Concepto de proceso y estados aplicados al sistema
  • PCB (Process Control Block) - gestión de procesos
  • Cambio de contexto en la práctica
  • Scripts de monitoreo funcionando en el proyecto
  • Servicios: Linux (systemctl) vs Windows (Get-Service)
  • Esta fase agrega capacidad de monitoreo al proyecto

FASE 3 (E3): Laboratorio de Optimización - 20%

  • Laboratorio Individual: 5 escenarios prácticos de optimización
  • Los estudiantes reciben la guía el 18 de Marzo y tienen 1 semana para completarla
  • Se trabaja en casa con la VM Ubuntu Server del proyecto
  • Gestión de memoria aplicada al servidor: paginación, segmentación
  • Memoria virtual y swap en el entorno del proyecto
  • Entrada/Salida y DMA - configuración práctica
  • Sistemas de archivos implementados en el proyecto
  • Sincronización: semáforos, mutex, deadlock (análisis práctico)
  • Entregable: PDF con capturas, comandos ejecutados y análisis técnico
  • Laboratorio que evalúa 4 competencias juntas (memoria + E/S + archivos + sincronización)

FASE 4 (E4): Seguridad y Hardening - 15%

  • Fase 4 del Proyecto: Aseguramiento del sistema
  • Mecanismos implementados: SELinux, AppArmor, UAC
  • Control de acceso: DAC, MAC, RBAC en el proyecto
  • Permisos avanzados: SUID, SGID, ACLs configurados
  • Hardening y auditoría del sistema del proyecto
  • Matriz de riesgos de seguridad aplicada
  • Esta fase asegura el sistema construido hasta el momento

FASE 5 (E5): Integración de Servicios - 15%

  • Fase 5 del Proyecto: Integración de servicios
  • Instalación y configuración de servidores web (Apache + IIS)
  • Monitoreo de sistemas en tiempo real implementado
  • Scripts de automatización funcionando
  • Integración de TODOS los conceptos del curso
  • Video demostración del funcionamiento
  • Esta fase muestra el sistema funcionando parcialmente

FASE 6 (E6): Entrega Proyecto Final - 20%

  • Fase 6 del Proyecto: Sistema completo operativo
  • Sustentación en vivo del proyecto (NO es examen escrito)
  • Demostración de servidores web funcionando
  • Ejecución de scripts de monitoreo en tiempo real
  • Defensa técnica de toda la implementación
  • Presentación de 20-30 minutos con demo en vivo
  • Entrega final que integra las 5 fases anteriores
