La Estructura de Directorios de Linux

Linux utiliza una estructura jerárquica de archivos que comienza en el directorio raíz (/). A diferencia de Windows, no hay unidades como C:, D:, etc.

Directorios Importantes

  • / - Directorio raíz (root)
  • /home - Directorios home de los usuarios
  • /bin - Binarios esenciales (comandos básicos)
  • /etc - Archivos de configuración del sistema
  • /var - Archivos variables (logs, spool, etc.)
  • /tmp - Archivos temporales
  • /usr - Programas y archivos de usuario

1. Comandos de Navegación

pwd - Print Working Directory

Muestra el directorio actual donde te encuentras.

Muestra el directorio actual donde te encuentras.

pwd

Salida: /home/tu_usuario

ls - List

Lista el contenido del directorio actual.

ls

Salida: Documents Downloads Pictures archivo.txt

💡 Tip: Usa ls -la para ver archivos ocultos y detalles adicionales.

cd - Change Directory

Cambia el directorio actual.

cd /tmp
pwd

Salida:

/tmp
Comando Descripción Ejemplo
cd .. Ir al directorio padre Sube un nivel en la jerarquía
cd ~ Ir al directorio home Te lleva a tu directorio personal
cd / Ir al directorio raíz Te lleva al inicio del sistema

2. Comandos de Creación y Edición

touch - Crear Archivo Vacío

touch mi_archivo.txt
ls

Salida:

mi_archivo.txt

mkdir - Make Directory

Crea un nuevo directorio.

mkdir mi_carpeta
ls

Salida:

mi_archivo.txt  mi_carpeta
💡 Tip: Usa mkdir -p ruta/a/nueva/carpeta para crear directorios anidados.

echo - Escribir en Archivos

Escribe texto en un archivo (sobrescribe o añade).

echo "Hola IF0099" > mi_archivo.txt
echo "Segunda línea" >> mi_archivo.txt
cat mi_archivo.txt

Salida:

Hola IF0099
Segunda línea
Operador Función Ejemplo
> Sobrescribe el archivo echo "texto" > archivo.txt
>> Añade al final del archivo echo "más" >> archivo.txt

3. Comandos de Visualización

cat - Concatenate and Display

Muestra el contenido completo de un archivo.

~ $ cat mi_archivo.txt
Hola IF0099
Segunda línea

less - Visualizador Paginado

Muestra el contenido página por página.

less mi_archivo.txt

Nota: Usa flechas para navegar, 'q' para salir

head y tail - Ver Inicio/Final

head -5 mi_archivo.txt

Nota: Muestra las primeras 5 líneas

4. Comandos de Eliminación

⚠️ ADVERTENCIA

Los comandos de eliminación en Linux NO tienen papelera de reciclaje. Una vez eliminado, el archivo se pierde permanentemente.

rm - Remove

Elimina archivos.

rm mi_archivo.txt
rm *.txt

Nota: El segundo comando elimina todos los archivos .txt

💡 Tip: Usa rm -i archivo.txt para pedir confirmación antes de eliminar.

rmdir - Remove Directory

Elimina directorios vacíos.

rmdir mi_carpeta
💡 Tip: Usa rm -r mi_carpeta para eliminar directorios con contenido.

5. Comandos de Ayuda

man - Manual

Muestra el manual completo de un comando.

man ls

Nota: Presiona 'q' para salir del manual

--help

Muestra ayuda resumida del comando.

ls --help

Nota: Muestra opciones disponibles de ls
