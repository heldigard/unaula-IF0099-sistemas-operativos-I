1. Auditoria de Usuarios

Archivos de Configuracion de Usuarios

/etc/passwd - Informacion de Usuarios

cat /etc/passwd | head -5
~ $ cat /etc/passwd | head -5
root:x:0:0:root:/root:/bin/bash
daemon:x:1:1:daemon:/usr/sbin:/usr/sbin/nologin
bin:x:2:2:bin:/bin:/usr/sbin/nologin

Estructura de /etc/passwd

code: username:password:UID:GID:GECOS:home:shell

  • username: Nombre de usuario
  • password: x (indica que esta en /etc/shadow)
  • UID: User ID (0=root, 1-999=sistema, 1000+=usuarios)
  • GID: Group ID primario
  • GECOS: Informacion adicional
  • home: Directorio home
  • shell: Shell por defecto

/etc/shadow - Contraseñas Seguras

sudo cat /etc/shadow | head -3

Seguridad de /etc/shadow

Este archivo solo debe ser legible por root. Contiene hashes de contraseñas. Nunca debe ser compartido o expuesto.

/etc/group - Informacion de Grupos

cat /etc/group | head -10

Comandos de Visualizacion

Comando Descripcion
id Muestra ID y grupos del usuario actual
id usuario Muestra ID y grupos de otro usuario
getent passwd Lista todos los usuarios
getent group Lista todos los grupos

Identificar Usuarios Especiales

# Usuarios con UID 0 (root)
grep ":0:" /etc/passwd

# Usuarios sin contraseña (sin shell)
grep "nologin\|false" /etc/passwd

# Usuarios que pueden hacer login
grep -v "nologin\|false" /etc/passwd | grep -v "^#"

# Contar usuarios regulares (UID >= 1000)
awk -F: '$3 >= 1000 {print $1}' /etc/passwd | wc -l

2. Comandos de Seguridad

chmod Avanzado

# Modo simbolico completo
chmod u+rwx,g+rx,o-rwx archivo

# Quitar todos los permisos a otros
chmod o-rwx archivo

# Establecer permisos exactos
chmod u=rw,g=r,o= archivo

# Recursivo en directorio
chmod -R 750 /directorio/

# Preservar directorios (ejecutable) pero archivos no
find /directorio -type f -exec chmod 640 {} \;
find /directorio -type d -exec chmod 750 {} \;

chown - Cambiar Propietario

~ $ sudo chown usuario:grupo archivo.txt
# Cambia usuario y grupo

~ $ sudo chown :grupo archivo.txt
# Solo cambia el grupo

~ $ sudo chown -R usuario:grupo /directorio/
# Recursivo

chattr y lsattr - Atributos Extendidos

Permiten establecer atributos especiales que protegen archivos incluso de root.

# Ver atributos actuales
lsattr archivo.txt

# Hacer archivo inmutable
sudo chattr +i archivo.txt

# Quitar atributo de inmutable
sudo chattr -i archivo.txt

# Solo permitir append
sudo chattr +a /var/log/importante.log
Atributo Significado Uso Tipico
+i Inmutable Proteger archivos criticos
+a Append-only Archivos de log
Tip de Seguridad: Usa chattr +i en archivos criticos de configuracion para prevenir modificaciones accidentales o maliciosas.

3. Firewall Basico con ufw

Instalacion y Estado

# Verificar si esta instalado
sudo apt install ufw -y

# Ver estado
sudo ufw status
sudo ufw status verbose
sudo ufw status numbered

Politicas Basicas

~ $ sudo ufw default deny incoming
Default incoming policy changed to 'deny'

~ $ sudo ufw default allow outgoing
Default outgoing policy changed to 'allow'

Permitir y Denegar Conexiones

# Permitir SSH
sudo ufw allow ssh
sudo ufw allow 22/tcp

# Permitir HTTP y HTTPS
sudo ufw allow http
sudo ufw allow https

# Permitir por rango de puertos
sudo ufw allow 6000:6007/tcp

# Permitir desde IP especifica
sudo ufw allow from 192.168.1.100

# Denegar puerto
sudo ufw deny 3306/tcp

# Eliminar regla
sudo ufw delete allow 80/tcp
sudo ufw delete 3

Habilitar y Deshabilitar

# Habilitar firewall
sudo ufw enable

# Deshabilitar firewall
sudo ufw disable

# Resetear a valores por defecto
sudo ufw reset

IMPORTANTE: No Bloquees tu Acceso

Si estas conectado por SSH, asegurate de permitir el puerto 22 ANTES de habilitar ufw, o perderas acceso al servidor.

Comando Descripcion
ufw status Ver estado y reglas
ufw enable/disable Activar/desactivar
ufw allow [servicio] Permitir trafico
ufw deny [servicio] Bloquear trafico

4. Analisis de Vulnerabilidades con lynis

Instalacion

sudo apt install lynis -y

Uso Basico

~ $ sudo lynis audit system
[ Lynis 3.0.0 ]

Initializing... Done
[+] Operating System
[+] Hostname, Domainname, etc.

Opciones Comunes

# Auditoria rapida
sudo lynis audit system --quick

# Solo tests especificos
sudo lynis audit system --tests-from-group authentication

# Generar reporte en archivo
sudo lynis audit system > lynis_report.txt 2>&1

Interpretando Resultados

Categorias de Recomendaciones

  • Warning: Problemas que deben corregirse
  • Suggestion: Mejoras recomendadas
  • Hardening Index: Puntuacion general (0-100)
# Ver puntuacion al final del reporte
grep "Hardening index" /var/log/lynis-report.dat
grep "suggestion\|warning" /var/log/lynis-report.dat

5. Checklist de Hardening

Checklist de Seguridad Basica (15 puntos)

  1. Actualizaciones: Mantener sistema actualizado (apt update && apt upgrade -y)
  2. Contraseñas: Configurar politica de contraseñas fuertes
  3. SSH: Deshabilitar login root via SSH (PermitRootLogin no)
  4. SSH: Cambiar puerto SSH de 22 a otro (Port 2222)
  5. SSH: Usar autenticacion solo por clave (PasswordAuthentication no)
  6. Firewall: Activar ufw con politica restrictiva
  7. Firewall: Permitir solo puertos necesarios (22, 80, 443)
  8. Usuarios: Eliminar o deshabilitar usuarios innecesarios
  9. Servicios: Deshabilitar servicios no utilizados
  10. Permisos: Verificar permisos de archivos criticos
  11. Logs: Configurar rotacion y monitoreo de logs
  12. Kernel: Aplicar parametros de seguridad (sysctl)
  13. SUID: Auditar y minimizar binarios con SUID
  14. Tmp: Configurar /tmp con noexec,nosuid,nodev
  15. Backups: Implementar estrategia de backup regular

Configuracion de SSH Seguro

# Editar configuracion
sudo nano /etc/ssh/sshd_config

# Cambios recomendados:
PermitRootLogin no
PasswordAuthentication no
PubkeyAuthentication yes
Port 2222
MaxAuthTries 3
ClientAliveInterval 300
ClientAliveCountMax 2

# Reiniciar SSH
sudo systemctl restart sshd

Parametros de Kernel (sysctl)

# Crear archivo de configuracion de seguridad
sudo tee /etc/sysctl.d/99-security.conf << EOF
# Deshabilitar IP source routing
net.ipv4.conf.all.accept_source_route = 0
net.ipv4.conf.default.accept_source_route = 0

# Deshabilitar ICMP redirect
net.ipv4.conf.all.accept_redirects = 0

# Proteccion contra SYN flood
net.ipv4.tcp_syncookies = 1

# Mejorar proteccion de memoria
kernel.randomize_va_space = 2
EOF

# Aplicar cambios
sudo sysctl -p /etc/sysctl.d/99-security.conf

6. Comandos de Auditoria

last - Historial de Logins

# Ultimos logins
last

# Logins de un usuario especifico

# Ultimos 10 logins
last -10

sudo lastb

w y who - Usuarios Conectados

w
who

Comando Que Muestra Permisos
last Logins exitosos Cualquiera

7. Ejercicios Practicos

Ejercicio 1: Auditoria de Usuarios

1 Ver tu informacion de usuario: 
id
id $(whoami)
2 Listar todos los usuarios del sistema: 
compgen -u | sort
cat /etc/passwd | cut -d: -f1
3 Encontrar usuarios con shell de login: 
grep -v "nologin\|false" /etc/passwd
4 Verificar permisos de /etc/shadow: 
ls -l /etc/shadow
5 Contar usuarios regulares: 
awk -F: '$3 >= 1000 && $3 < 65534 {print $1}' /etc/passwd

Ejercicio 2: Seguridad de Archivos

1 Crear archivo de prueba y establecer permisos seguros: 
touch ~/secreto.txt
echo "informacion confidencial" > ~/secreto.txt
chmod 600 ~/secreto.txt
ls -l ~/secreto.txt
2 Hacer archivo inmutable: 
sudo chattr +i ~/secreto.txt
lsattr ~/secreto.txt
# Intentar modificar (fallara)
echo "nuevo" >> ~/secreto.txt
3 Quitar atributo inmutable: 
sudo chattr -i ~/secreto.txt
rm ~/secreto.txt
4 Verificar permisos de archivos criticos: 
ls -l /etc/passwd /etc/shadow /etc/group

Ejercicio 3: Configuracion de Firewall

1 Instalar y verificar ufw: 
sudo apt install ufw -y
sudo ufw status
2 Configurar politicas por defecto: 
sudo ufw default deny incoming
sudo ufw default allow outgoing
3 Permitir SSH antes de habilitar: 
sudo ufw allow ssh
sudo ufw allow 22/tcp
4 Habilitar firewall: 
sudo ufw enable
sudo ufw status verbose

Ejercicio 4: Auditoria con lynis

1 Instalar lynis: 
sudo apt install lynis -y
2 Ejecutar auditoria basica: 
sudo lynis audit system --quick
3 Ver reporte: 
sudo grep -E "(warning|suggestion)" /var/log/lynis-report.dat | head -10
4 Ver puntuacion: 
sudo grep "hardening_index" /var/log/lynis-report.dat

8. Desafio: Script de Auditoria de Seguridad

Desafio: Sistema Completo de Auditoria de Seguridad

Crea un script que realice auditoria completa y genere reporte HTML:

1 Crear script de auditoria:

echo "Generando auditoria..."

# Crear HTML
cat > $REPORTE << EOF


Auditoria de Seguridad




Reporte de Auditoria de Seguridad


Servidor: $HOSTNAME | Fecha: $FECHA



1. Estado de Usuarios




VerificacionEstado


Usuarios con UID 0$(grep ":0:" /etc/passwd | wc -l) usuarios


Usuarios con shell valido$(grep -v "nologin\|false" /etc/passwd | wc -l) usuarios


Usuarios sin contraseña$(sudo awk -F: '($2 == "" || $2 == "*" || $2 == "!") {print}' /etc/shadow | wc -l) usuarios





2. Estado del Firewall




VerificacionEstado


UFW instalado$(which ufw >/dev/null 2>&1 && echo "Instalado" || echo "No instalado")


UFW activo$(sudo ufw status 2>/dev/null | grep -q "Status: active" && echo "Activo" || echo "Inactivo")

$(apt list --upgradable 2>/dev/null | head -10)

$(ss -tuln 2>/dev/null | head -15)

ENDSCRIPT
2 Hacer ejecutable y ejecutar:
