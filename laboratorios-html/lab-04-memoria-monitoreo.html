1. Comandos de Memoria

free - Informacion de Memoria

Muestra el uso total de memoria RAM y swap del sistema.

~ $ free -h
total used free shared buff/cache available
Mem: 7.7Gi 2.1Gi 3.2Gi 256Mi 2.4Gi 5.1Gi
Swap: 2.0Gi 0B 2.0Gi
Tip: La opcion -h muestra los valores en formato humano-legible (GB, MB).

vmstat - Estadisticas del Sistema

Reporta estadisticas de procesos, memoria, paginacion, bloqueo de E/S, traps y actividad de CPU.

~ $ vmstat 1 5
procs -----------memory---------- ---swap-- -----io---- -system-- ------cpu-----
r b swpd free buff cache si so bi bo in cs us sy id wa st
2 0 0 3321456 234512 1890234 0 0 12 34 123 456 5 2 91 2 0

El comando anterior muestra estadisticas cada 1 segundo, 5 veces.

/proc/meminfo - Informacion Detallada

Archivo virtual del kernel con informacion detallada de memoria.

cat /proc/meminfo | head -20

Campos Importantes de /proc/meminfo

  • MemTotal - Memoria RAM total
  • MemFree - Memoria completamente libre
  • MemAvailable - Memoria disponible para nuevas aplicaciones
  • Buffers - Cache de buffers del kernel
  • Cached - Cache de paginas
  • SwapTotal/SwapFree - Informacion de swap
Comando Descripcion Uso Tipico
free Resumen de memoria free -h
vmstat Estadisticas virtuales vmstat 1 10
cat /proc/meminfo Detalles del kernel cat /proc/meminfo | grep Mem
top Procesos en tiempo real Presiona 'M' para ordenar por memoria

2. Monitoreo de Disco

df - Espacio en Disco

Muestra el espacio disponible en los sistemas de archivos montados.

df -h

Muestra uso de disco en formato humano-legible

du - Uso de Disco por Archivos

Estima el uso de espacio de archivos y directorios.

~ $ du -sh /var/log
245M /var/log
Tip: du -sh * muestra el tamaño de todos los archivos/directorios en la ubicacion actual.

iostat - Estadisticas de E/S

Primero instala el paquete sysstat:

sudo apt install sysstat -y

Uso de iostat:

~ $ iostat -x 1 5
Linux 5.15.0-91-generic (server) 02/15/2026 _x86_64_ (4 CPU)

avg-cpu: %user %nice %system %iowait %steal %idle
1.23 0.00 0.45 0.12 0.00 98.20
lsblk
Comando Funcion Ejemplo
df -h Espacio libre en filesystems df -h /home
du -sh Tamaño de directorio du -sh /var
iostat Estadisticas de E/S iostat -x 1
Informacion de bloques lsblk -f

3. Monitoreo de Red

netstat - Conexiones de Red

Muestra conexiones de red, tablas de routing, estadisticas de interfaces.

sudo apt install net-tools -y
netstat -tuln

Opciones Comunes de netstat

  • -t - Conexiones TCP
  • -u - Conexiones UDP
  • -l - Solo sockets en escucha
  • -n - Muestra direcciones numericas
  • -p - Muestra PID/programa

ss - Socket Statistics (Reemplazo de netstat)

Comando moderno mas rapido que netstat.

~ $ ss -tuln
State Recv-Q Send-Q Local Address:Port Peer Address:Port Process
LISTEN 0 4096 127.0.0.53%lo:53 0.0.0.0:*
LISTEN 0 128 0.0.0.0:22 0.0.0.0:*

lsof - Archivos Abiertos

Lista archivos abiertos y los procesos que los usan.

lsof -i :22

Muestra que proceso usa el puerto 22 (SSH)

iftop - Monitoreo de Ancho de Banda

Visualiza el uso de ancho de banda en tiempo real.

sudo apt install iftop -y
sudo iftop -i eth0
Comando Proposito Uso
netstat -tuln Puertos en escucha Ver servicios activos
ss -tuln Puertos (moderno) Alternativa rapida a netstat
lsof -i :PORT Proceso por puerto Identificar que usa un puerto
iftop Ancho de banda Monitoreo en tiempo real
ping Conectividad ping -c 4 google.com

4. Comandos de Sistema

uptime - Tiempo de Actividad

Muestra cuanto tiempo lleva encendido el sistema y carga promedio.

~ $ uptime
14:32:15 up 15 days, 3:45, 2 users, load average: 0.12, 0.08, 0.05

w - Usuarios Conectados

Muestra quien esta conectado y que esta haciendo.

w

who - Usuarios Logueados

Lista usuarios actualmente conectados.

who

Interpretando load average

Los tres numeros representan la carga promedio del sistema en los ultimos 1, 5 y 15 minutos. Un valor cercano al numero de CPUs indica carga optima. Valores mayores indican sobrecarga.

5. Script Integral de Monitoreo

Crea un script que genere un reporte HTML completo del sistema:

~ $ cat > monitor_system.sh << 'EOF'
#!/bin/bash

REPORTE="/tmp/reporte_sistema_$(date +%Y%m%d_%H%M%S).html"

echo "" > $REPORTE
echo "Reporte del Sistema" >> $REPORTE
echo "" >> $REPORTE
echo "" >> $REPORTE
echo "

Reporte del Sistema - $(date)

" >> $REPORTE

echo "

Uptime

$(uptime)
" >> $REPORTE

echo "

Memoria

$(free -h)
" >> $REPORTE

echo "

Disco

$(df -h)
" >> $REPORTE

echo "

Usuarios Conectados

$(who)
" >> $REPORTE

echo "

Puertos en Escucha

$(ss -tuln)
" >> $REPORTE

echo "" >> $REPORTE

echo "Reporte generado: $REPORTE"
EOF
1 Hacer ejecutable el script: 
chmod +x monitor_system.sh
2 Ejecutar el script: 
./monitor_system.sh
3 Ver el reporte generado: 
cat /tmp/reporte_sistema_*.html

6. Ejercicios Practicos

Ejercicio 1: Analisis de Memoria

1 Ver uso actual de memoria: 
free -h
2 Ver estadisticas de memoria cada 2 segundos (5 veces): 
vmstat 2 5
3 Filtrar informacion relevante de /proc/meminfo: 
cat /proc/meminfo | grep -E "(MemTotal|MemFree|MemAvailable|Swap)"
4 Identificar los 5 procesos que mas memoria usan: 
ps aux --sort=-%mem | head -6

Ejercicio 2: Monitoreo de Disco

1 Ver espacio disponible en todos los filesystems: 
df -h
2 Encontrar los 10 directorios mas grandes en /var: 
sudo du -h /var | sort -rh | head -10
3 Instalar y usar iostat: 
sudo apt install sysstat -y
iostat -x 1 3
4 Ver informacion de bloques y filesystems: 
lsblk -f

Ejercicio 3: Monitoreo de Red

1 Ver todas las conexiones TCP/UDP en escucha: 
sudo ss -tuln
2 Identificar que proceso usa el puerto 22: 
sudo lsof -i :22
3 Ver tabla de routing: 
ip route
4 Ver estadisticas de interfaces de red: 
ip -s link

Ejercicio 4: Informacion del Sistema

1 Ver tiempo de actividad y carga: 
uptime
2 Ver usuarios conectados y sus actividades: 
w
3 Listar usuarios logueados: 
who
4 Ver informacion del kernel y sistema: 
uname -a
cat /etc/os-release

7. Desafio: Dashboard de Monitoreo

Desafio: Crear Dashboard HTML de Monitoreo en Tiempo Real

Crea un script avanzado que genere un dashboard HTML con actualizacion automatica:

1 Crear el script del dashboard: 
cat > dashboard_monitor.sh << 'EOF'
#!/bin/bash

HTML_FILE="/var/www/html/dashboard.html"
mkdir -p /var/www/html

generate_dashboard() {
cat > $HTML_FILE << 'HTMLEOF'



    
    Dashboard de Monitoreo
    


    

        
Dashboard de Monitoreo del Sistema

        
Ultima actualizacion: HTMLEOF
echo "$(date '+%Y-%m-%d %H:%M:%S')" >> $HTML_FILE
cat >> $HTML_FILE << 'HTMLEOF'


        
        

            
Estado General

            

                
Uptime

                
HTMLEOF
echo "$(uptime | awk -F',' '{print $1}' | awk '{print $3,$4}')" >> $HTML_FILE
cat >> $HTML_FILE << 'HTMLEOF'


            

            

                
Usuarios

                
HTMLEOF
echo "$(who | wc -l)" >> $HTML_FILE
cat >> $HTML_FILE << 'HTMLEOF'


            

            

                
Carga

                
HTMLEOF
echo "$(uptime | awk -F'load average:' '{print $2}' | awk '{print $1}')" >> $HTML_FILE
cat >> $HTML_FILE << 'HTMLEOF'


            

        

        
        

            
Memoria

            
HTMLEOF
free -h >> $HTML_FILE
cat >> $HTML_FILE << 'HTMLEOF'


        

        
        

            
Disco

            
HTMLEOF
df -h >> $HTML_FILE
cat >> $HTML_FILE << 'HTMLEOF'


        

        
        

            
Procesos Principales

            
HTMLEOF
ps aux --sort=-%cpu | head -11 >> $HTML_FILE
cat >> $HTML_FILE << 'HTMLEOF'


        

        
        

            
Conexiones de Red

            
HTMLEOF
ss -tuln >> $HTML_FILE
cat >> $HTML_FILE << 'HTMLEOF'


        

    



HTMLEOF
}

generate_dashboard
echo "Dashboard generado en: $HTML_FILE"
EOF
2 Hacer ejecutable y probar: 
chmod +x dashboard_monitor.sh
sudo ./dashboard_monitor.sh
3 Instalar un servidor web ligero para ver el dashboard: 
sudo apt install nginx -y
sudo cp /var/www/html/dashboard.html /var/www/html/index.html
4 Automatizar con cron (actualizar cada minuto): 
sudo crontab -e
# Agregar esta linea:
* * * * * /home/$(whoami)/dashboard_monitor.sh
Tip: Puedes acceder al dashboard desde tu navegador usando la IP de tu VM. Asegurate de que el puerto 80 este abierto en el firewall.
