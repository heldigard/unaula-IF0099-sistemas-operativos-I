1. Tipos de Sistemas de Archivos

Comparativa de Sistemas de Archivos

Sistema Plataforma Tamano Max Archivo Tamano Max Volumen Caracteristicas
ext4 Linux 16 TB 1 EB Journaling, extents, mejoras en rendimiento
XFS Linux 8 EB 8 EB Alto rendimiento, paralelizacion, ideal para grandes archivos
NTFS Windows 16 EB 256 TB Journaling, ACLs, compresion, cifrado
FAT32 Multiplataforma 4 GB 2 TB Compatible universal, limitado, sin permisos
btrfs Linux 16 EB 16 EB Copy-on-write, snapshots, checksums, RAID integrado

Verificar Sistema de Archivos Actual

df -T
cat /etc/fstab

Journaling

Es una tecnica que registra los cambios antes de aplicarlos al sistema de archivos. Esto permite recuperacion rapida despues de un corte de energia o crash del sistema. ext4 y XFS usan journaling; FAT32 no lo tiene.

2. Comandos Avanzados

find - Busqueda Avanzada

Busca archivos y directorios segun multiples criterios.

~ $ find /var/log -name "*.log" -mtime +7
/var/log/syslog.1
/var/log/auth.log.1
Opcion Descripcion Ejemplo
-name Por nombre (case sensitive) find . -name "*.txt"
-iname Por nombre (case insensitive) find . -iname "*.jpg"
-size Por tamano find . -size +100M
-mtime Modificado hace N dias find . -mtime -7
-type Por tipo (f=archivo, d=directorio) find . -type d
-exec Ejecuta comando en resultados find . -exec ls -lh {} \;
-delete Elimina archivos encontrados find . -name "*.tmp" -delete

locate - Busqueda Rapida

Busca en una base de datos preconstruida (mas rapido que find).

# Actualizar la base de datos
sudo updatedb

# Buscar archivos
locate *.conf
locate -i nginx
Tip: locate no busca en directorios configurados en /etc/updatedb.conf (tipicamente /tmp, /var/tmp). Para busquedas en tiempo real, usa find.

tar - Archivado

Crea archivos comprimidos (.tar) de multiples archivos y directorios.

~ $ tar -cvf backup.tar /home/usuario/documentos
home/usuario/documentos/
home/usuario/documentos/archivo1.txt
home/usuario/documentos/archivo2.txt
Opcion Significado
-c Crear archivo
-x Extraer
-v Verbose (muestra progreso)
-f Especifica nombre de archivo
-z Comprimir con gzip (.tar.gz)
-j Comprimir con bzip2 (.tar.bz2)

gzip y gunzip - Compresion

# Comprimir archivo
gzip archivo.txt
# Resultado: archivo.txt.gz

# Descomprimir
gunzip archivo.txt.gz

# Ver contenido sin descomprimir
zcat archivo.txt.gz

rsync - Sincronizacion

Herramienta poderosa para copiar y sincronizar archivos (local y remoto).

~ $ rsync -avz --progress /origen/ /destino/
sending incremental file list
./
archivo1.txt
1,234 100% 1.21MB/s 0:00:00 (xfr#1, to-chk=2/4)
Opcion Descripcion
-a Modo archivo (preserva permisos, enlaces, etc.)
-v Verbose
-z Comprime durante transferencia
--progress Muestra progreso
--delete Elimina archivos en destino que no estan en origen
-n Dry-run (simulacion, no copia nada)

3. Permisos Avanzados

SUID (Set User ID)

Permite que un archivo ejecutable se ejecute con los permisos del propietario, no del usuario que lo ejecuta.

# Ver archivos con SUID
find /usr/bin -perm -4000 -ls

# Establecer SUID (4xxx)
chmod 4755 script.sh
# O
chmod u+s script.sh

ADVERTENCIA: Riesgos de SUID

Los archivos con SUID son potencialmente peligrosos. Si tienen vulnerabilidades, pueden ser explotados para escalar privilegios. Solo deben usarse cuando sea absolutamente necesario.

SGID (Set Group ID)

Similar a SUID pero para el grupo. En directorios, hace que los archivos nuevos hereden el grupo del directorio.

# Establecer SGID en directorio (2xxx)
chmod 2775 /compartido/proyecto/
# O
chmod g+s /compartido/proyecto/

# Ver archivos con SGID
find / -perm -2000 -type f 2>/dev/null

Sticky Bit

En directorios, solo el propietario puede eliminar o renombrar sus archivos (aunque otros tengan permisos de escritura).

# Ejemplo clasico: /tmp tiene sticky bit
ls -ld /tmp
# drwxrwxrwt 12 root root ... /tmp

# Establecer sticky bit (1xxx)
chmod 1777 /compartido/temp/
# O
chmod +t /compartido/temp/
Permiso Especial Octal Simbolico Efecto en Archivos Efecto en Directorios
SUID 4000 u+s Ejecuta como propietario Ninguno
SGID 2000 g+s Ejecuta como grupo Archivos heredan grupo
Sticky Bit 1000 +t Sin efecto Solo propietario puede borrar
Mnemotecnia: SUID=4, SGID=2, Sticky=1. Orden: U-G-T (Usuario-Grupo-Temp).

4. Access Control Lists (ACLs)

Instalacion

sudo apt install acl -y

setfacl - Establecer ACLs

Permite asignar permisos especificos a usuarios y grupos individuales.

~ $ setfacl -m u:maria:rw documento.txt
# Otorga lectura y escritura al usuario maria

getfacl - Ver ACLs

getfacl documento.txt
~ $ getfacl documento.txt
# file: documento.txt
# owner: juan
# group: desarrollo
user::rw-
user:maria:rw-
group::r--
mask::rw-
other::r--

ACLs en Directorios (Default ACLs)

# Establecer ACL por defecto en directorio
setfacl -d -m u:maria:rwX proyectos/

# Recursivo en directorio existente
setfacl -R -m u:maria:rwX proyectos/

# Eliminar ACL especifico
setfacl -x u:maria documento.txt

# Eliminar todas las ACLs
setfacl -b documento.txt
Opcion Descripcion
-m Modificar ACL
-x Eliminar ACL
-b Eliminar todas las ACLs
-d ACL por defecto (para directorios)
-R Recursivo

5. Compresion y Backup

Combinando tar con compresion

# Crear tar.gz (gzip)
tar -czvf backup.tar.gz /ruta/a/respaldar

# Crear tar.bz2 (bzip2 - mejor compresion, mas lento)
tar -cjvf backup.tar.bz2 /ruta/a/respaldar

# Crear tar.xz (xz - maxima compresion)
tar -cJvf backup.tar.xz /ruta/a/respaldar

# Extraer
tar -xzvf backup.tar.gz     # gzip
tar -xjvf backup.tar.bz2    # bzip2
tar -xJvf backup.tar.xz     # xz

Comparativa de Algoritmos de Compresion

Formato Comando Velocidad Ratio Uso Recomendado
.tar.gz gzip Rapida Buena Uso general
.tar.bz2 bzip2 Media Muy buena Archivos de texto
.tar.xz xz Lenta Excelente Distribuciones, archivos grandes

rsync para Backup Incremental

# Backup local con preservacion completa
rsync -avz --delete /origen/ /backup/origen/

# Backup a servidor remoto
rsync -avz -e ssh /origen/ usuario@servidor:/ruta/backup/

# Backup con exclusiones
rsync -avz --exclude='*.tmp' --exclude='cache/' /origen/ /backup/

# Backup con hardlinks (copia solo cambios, conserva historial)
rsync -avz --link-dest=/backup/anterior/ /origen/ /backup/actual/

Backup Incremental vs Diferencial

  • Incremental: Solo respalda archivos modificados desde el ultimo backup (de cualquier tipo)
  • Diferencial: Respalda archivos modificados desde el ultimo backup completo
  • Completo: Respalda todo

6. Ejercicios Practicos

Ejercicio 1: Busqueda con find

1 Buscar todos los archivos .log mayores a 10MB en /var: 
sudo find /var -name "*.log" -size +10M
2 Buscar archivos modificados en las ultimas 24 horas: 
find ~ -mtime -1 -type f
3 Buscar y eliminar archivos temporales: 
find /tmp -name "*.tmp" -mtime +7 -delete
4 Buscar archivos vacios: 
find ~ -type f -empty

Ejercicio 2: Compresion y Archivado

1 Crear estructura de prueba: 
mkdir -p ~/prueba_backup/{docs,imgs,scripts}
touch ~/prueba_backup/docs/{a,b,c}.txt
touch ~/prueba_backup/imgs/{1,2,3}.jpg
echo "#!/bin/bash" > ~/prueba_backup/scripts/test.sh
2 Crear backup comprimido: 
tar -czvf ~/backup_prueba_$(date +%Y%m%d).tar.gz ~/prueba_backup

tar -cjvf ~/backup_prueba.tar.bz2 ~/prueba_backup
ls -lh ~/backup_prueba.*
4 Extraer y verificar: 
mkdir ~/restaurado
tar -xzvf ~/backup_prueba_*.tar.gz -C ~/restaurado
ls -la ~/restaurado

7. Desafio: Script de Backup Automatizado

Desafio: Sistema de Backup Rotativo con rsync

Crea un script que implemente una estrategia de backup GFS (Grandfather-Father-Son) con retencion:

1 Crear el script de backup avanzado: 
cat > backup_rotativo.sh << 'EOF'
#!/bin/bash

# Configuracion
SOURCE_DIR="/home/$(whoami)"
BACKUP_DIR="/backup"
LOG_FILE="/var/log/backup.log"
RETENTION_DAILY=7
RETENTION_WEEKLY=4
RETENTION_MONTHLY=12

# Funcion para logging
log() {
    echo "[$(date '+%Y-%m-%d %H:%M:%S')] $1" | tee -a "$LOG_FILE"
}

# Crear directorios de backup
crear_estructura() {
    mkdir -p "$BACKUP_DIR"/{diario,semanal,mensual}
    log "Estructura de backup creada"
}

# Backup dieno
backup_diario() {
    local fecha=$(date +%Y%m%d)
    local destino="$BACKUP_DIR/diario/backup_$fecha.tar.gz"
    
    log "Iniciando backup dieno: $destino"
    
    tar -czf "$destino" \
        --exclude="*.tmp" \
        --exclude="cache" \
        --exclude=".cache" \
        "$SOURCE_DIR" 2>> "$LOG_FILE"
    
    if [ $? -eq 0 ]; then
        log "Backup dieno completado: $(du -h "$destino" | cut -f1)"
    else
        log "ERROR: Backup dieno fallo"
    fi
}

# Limpiar backups antiguos
limpiar_antiguos() {
    log "Limpiando backups antiguos..."
    
    # Mantener solo los ultimos N backups diarios
    find "$BACKUP_DIR/diario" -name "backup_*.tar.gz" -mtime +$RETENTION_DAILY -delete
    
    # Mantener solo los ultimos N backups semanales
    find "$BACKUP_DIR/semanal" -name "backup_*.tar.gz" -mtime +$((RETENTION_WEEKLY * 7)) -delete
    
    log "Limpieza completada"
}

# Rotacion semanal (ejecutar domingos)
rotacion_semanal() {
    if [ "$(date +%u)" -eq 7 ]; then
        local fecha=$(date +%Y%m%d)
        cp "$BACKUP_DIR/diario/backup_$fecha.tar.gz" \
           "$BACKUP_DIR/semanal/semanal_$fecha.tar.gz"
        log "Rotacion semanal creada"
    fi
}

# Rotacion mensual (primer dia del mes)
rotacion_mensual() {
    if [ "$(date +%d)" -eq 01 ]; then
        local fecha=$(date +%Y%m%d)
        cp "$BACKUP_DIR/diario/backup_$fecha.tar.gz" \
           "$BACKUP_DIR/mensual/mensual_$fecha.tar.gz"
        log "Rotacion mensual creada"
    fi
}

# Verificar integridad del ultimo backup
verificar_integridad() {
    local ultimo=$(ls -t "$BACKUP_DIR/diario"/backup_*.tar.gz 2>/dev/null | head -1)
    if [ -n "$ultimo" ]; then
        log "Verificando integridad de: $ultimo"
        if tar -tzf "$ultimo" > /dev/null 2>> "$LOG_FILE"; then
            log "Integridad verificada correctamente"
        else
            log "ERROR: Problema de integridad en backup"
        fi
    fi
}

# Reporte de estado
generar_reporte() {
    echo "=== REPORTE DE BACKUP ==="
    echo "Fecha: $(date)"
    echo ""
    echo "Espacio usado:"
    du -sh "$BACKUP_DIR"/* 2>/dev/null
    echo ""
    echo "Ultimos 5 backups:"
    ls -ltr "$BACKUP_DIR"/*/*.tar.gz 2>/dev/null | tail -5
    echo ""
    echo "Estado del log:"
    tail -10 "$LOG_FILE"
}

# Ejecucion principal
case "${1:-backup}" in
    backup)
        crear_estructura
        backup_diario
        rotacion_semanal
        rotacion_mensual
        limpiar_antiguos
        verificar_integridad
        ;;
    reporte)
        generar_reporte
        ;;
    limpiar)
        limpiar_antiguos
        ;;
    *)
        echo "Uso: $0 {backup|reporte|limpiar}"
        exit 1
        ;;
esac

log "=== Proceso de backup finalizado ==="
EOF
2 Hacer ejecutable y probar: 
chmod +x backup_rotativo.sh
./backup_rotativo.sh
3 Ver reporte: 
./backup_rotativo.sh reporte
4 Configurar cron para ejecucion diaria: 
crontab -e
# Agregar al final:
0 2 * * * /home/$(whoami)/backup_rotativo.sh >> /var/log/backup_cron.log 2>&1
Extension del desafio: Modifica el script para incluir:
  • Backup remoto via rsync sobre SSH
  • Notificacion por correo si el backup falla
  • Encriptacion de backups con gpg
  • Exclusiones configurables desde archivo externo
