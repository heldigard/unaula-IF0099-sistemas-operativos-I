El Sistema de Permisos de Linux

Linux utiliza un sistema de permisos basado en tres categorías:

Estructura de Permisos

-rwxr-xr--
rwx

Usuario (Owner)

r-x

Grupo

r--

Otros

r = Read (lectura) | w = Write (escritura) | x = Execute (ejecución)

Tipos de Archivos

Acceso directo a otro archivo

Símbolo Tipo Descripción
- Archivo regular Archivo de datos o texto
d Directorio Carpeta que contiene archivos
l Enlace simbólico

Ver Permisos: ls -l

El comando ls -l muestra información detallada incluyendo permisos:

ls -l

Salida de ejemplo:

drwxr-xr-x  2 root root  4096 Jan 15 10:30 Documents
-rw-r--r--  1 root root  1234 Jan 15 10:31 archivo.txt
-rwxr-xr-x  1 root root  5678 Jan 15 10:32 script.sh

Anatomía de la Salida

-rw-r--r--  1  root  root  1234  Jan 15 10:31  archivo.txt
││││││││  │  │     │     │     │          │
││││││││  │  │     │     │     │          └─ Nombre del archivo
││││││││  │  │     │     │     └──────────── Fecha de modificación
││││││││  │  │     │     └────────────────── Tamaño en bytes
││││││││  │  │     └─────────────────────── Grupo
││││││││  │  └───────────────────────────── Propietario
││││││││  └──────────────────────────────── Número de enlaces
│││└└└└┴────────────────────────────────── Permisos grupo
││└└└┴──────────────────────────────────── Permisos propietario
└└─────────────────────────────────────── Tipo de archivo

chmod - Cambiar Permisos

El comando chmod modifica los permisos de archivos y directorios.

Modo Simbólico

Categoría Símbolo Operador Permiso Ejemplo
Usuario (u) u + (añadir) r (read) chmod u+x archivo
Grupo (g) g - (quitar) w (write) chmod g-w archivo
Otros (o) o = (asignar) x (execute) chmod o=r archivo
Todos (a) a chmod a+x archivo

Modo Octal (Numérico)

Número Binario Permisos Significado
0 000 --- Sin permisos
1 001 --x Solo ejecución
2 010 -w- Solo escritura
3 011 -wx Escritura y ejecución
4 100 r-- Solo lectura
5 101 r-x Lectura y ejecución
6 110 rw- Lectura y escritura
7 111 rwx Todos los permisos

Ejemplos Comunes

  • chmod 644 archivo - rw-r--r-- (archivo normal)
  • chmod 755 script.sh - rwxr-xr-x (script ejecutable)
  • chmod 700 privado.txt - rwx------ (solo propietario)
  • chmod 777 directorio - rwxrwxrwx (todos, usar con cuidado)

chown - Cambiar Propietario

El comando chown cambia el propietario de un archivo.

chown usuario archivo.txt
chown usuario:grupo archivo.txt
chown -R usuario:grupo directorio/

Actividad Práctica

Ejercicio 1: Interpretar Permisos

En tu VM de Ubuntu Server, examina los permisos de varios archivos:

1 Listar con detalles: 
ls -la /bin
2 Identificar: ¿Cuáles son ejecutables? ¿Cómo lo sabes?
3 Examinar un directorio: 
ls -la /etc
4 Preguntarse: ¿Por qué algunos archivos no tienen permisos de escritura para nadie?

Ejercicio 2: Modificar Permisos

1 Crear archivo de prueba: 
echo "prueba" > test.txt
ls -l test.txt
2 Quitar todos los permisos: 
chmod 000 test.txt
ls -l test.txt
3 Intentar leer: 
cat test.txt

¿Qué sucede?

4 Restaurar permisos: 
chmod 644 test.txt
ls -l test.txt

Ejercicio 3: Crear Script Ejecutable

1 Crear un script: 
echo '#!/bin/bash' > mi_script.sh
echo 'echo "Hola desde IF0099"' >> mi_script.sh
cat mi_script.sh
2 Verificar permisos iniciales: 
ls -l mi_script.sh

¿Es ejecutable?

3 Hacerlo ejecutable: 
chmod +x mi_script.sh
ls -l mi_script.sh
4 Ejecutar el script: 
./mi_script.sh
5 Probar diferentes métodos: 
bash mi_script.sh
sh mi_script.sh

¿Cuál es la diferencia?

Ejercicio 4: Permisos de Directorios

1 Crear estructura: 
mkdir -p test_permisos/dentro
echo "contenido" > test_permisos/archivo.txt
2 Quitar permiso de lectura: 
chmod -r test_permisos
ls -la
3 Intentar listar: 
ls test_permisos

¿Qué sucede?

4 Restaurar y quitar ejecución: 
chmod u+r test_permisos
chmod -x test_permisos
cd test_permisos

¿Puedes entrar al directorio?

5Limpiar: 
cd ..
chmod 755 test_permisos
rm -rf test_permisos

Conceptos Clave

Permisos de Directorios vs Archivos

Permiso En Archivos En Directorios
r (read) Puede leer el contenido Puede listar los archivos (con ls)
w (write) Puede modificar el contenido Puede crear/eliminar archivos
x (execute) Puede ejecutar como programa Puede entrar al directorio (cd)

💡 Regla de Oro

Para poder eliminar un archivo de un directorio, necesitas permiso de escritura en el directorio, no necesariamente en el archivo mismo.

Desafío Adicional

🎯 Desafío: Permisos Seguros

Crea un sistema de archivos con permisos seguros para un escenario de equipo:

  1. Crea un directorio proyecto_equipo
  2. Dentro, crea subdirectorios: compartido, privado, publico
  3. Configura los permisos de tal manera que:
    • compartido: El equipo pueda leer/escribir, otros solo leer
    • privado: Solo el propietario pueda acceder
    • publico: Todos puedan leer y ejecutar
  4. Crea archivos de prueba en cada directorio
  5. Documenta los comandos usados y los permisos resultantes

  4. ¿Qué riesgos hay al usar chmod 777 indiscriminadamente?
  5. ¿Cómo proteges un archivo que contiene contraseñas?
