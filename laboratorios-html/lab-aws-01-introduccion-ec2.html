¿Qué es AWS EC2?

Amazon Elastic Compute Cloud (EC2) es un servicio que proporciona capacidad de computación escalable en la nube de AWS. En términos simples:

Analogía

EC2 es como alquilar una computadora en la nube. Puedes elegir el sistema operativo, el tamaño (RAM, CPU), y solo pagas por el tiempo que la usas.

AWS Free Tier: Qué es GRATIS

Para estudiantes nuevos en AWS, Amazon ofrece 12 meses de servicios gratis:

Servicio Límite Gratuito Duración Estado
EC2 (t2.micro o t3.micro) 750 horas/mes 12 meses GRATIS
Almacenamiento EBS 30 GB 12 meses GRATIS
Transferencia de datos 100 GB/mes 12 meses GRATIS
EC2 (más grande que t2.micro) - - PAGA
IP elástica (cuando instancia apagada) - - PAGA

💡 Cómo Mantenerlo Gratis

  • Usa solo instancias t2.micro o t3.micro
  • Mantén menos de 30 GB de almacenamiento
  • APAGA la instancia cuando no la uses
  • NO uses IP elástica (usar IP pública)
  • Libera la instancia cuando termines el curso

Paso 1: Crear Cuenta AWS

1 Ir a AWS: Visita https://aws.amazon.com/es/
2 Crear cuenta: Haz clic en "Crear una cuenta de AWS"
3 Información requerida:
  • Correo electrónico
  • Nombre de la cuenta de AWS
  • Tarjeta de crédito internacional
NOTA: AWS requiere una tarjeta de crédito para verificar la identidad. NO harán cargos si respetas los límites del Free Tier.
4 Verificación:
  • AWS hará un cargo temporal de ~$1 USD (se devuelve)
  • Pueden llamar a tu teléfono para verificar
  • El proceso toma 5-10 minutos
5 Seleccionar plan de soporte: Elige "Plan básico - Gratis"

Paso 2: Configurar Alertas de Presupuesto

🚨 ANTES DE LANZAR CUALQUIER INSTANCIA

Configura alertas de presupuesto para recibir notificaciones si estás por generar costos.

1 Ir a Billing: Console → Billing → Budgets
2 Crear presupuesto:
  • Nombre: "Presupuesto IF0099"
  • Presupuesto: $0.00 USD
  • Alerta al 100%: Enviar correo electrónico
3 Configurar notificaciones: Agrega tu correo para recibir alertas

Paso 3: Lanzar Primera Instancia EC2

1 Ir a EC2: Console → Services → EC2
2 Lanzar instancia: Haz clic en "Launch Instance"
3 Configurar instancia:
Name: IF0099-Lab01
OS: Ubuntu Server 22.04 LTS (HVM)
Type: t2.micro (Free Tier eligible)
Key pair: Crear nuevo (ver abajo)
Network: Default (sin IP elástica)
4 Crear Key Pair (CRÍTICO):
  • Nombre: "if0099-key"
  • Tipo: RSA
  • Formato: .pem (para OpenSSH)
  • DESCARGAR y guardar (no se puede volver a descargar)
⚠️ PERDER LA KEY = PERDER ACCESO

Si pierdes tu key pair, no podrás acceder a la instancia nunca más.

5 Configurar Security Group:
  • SSH: Port 22, Source: My IP (o tu IP actual)
  • HTTP: Port 80 (opcional, para web)
  • HTTPS: Port 443 (opcional, para web)
6 Lanzar: Revisa y haz clic en "Launch"

✅ ¡Felicidades!

Tu instancia está creándose. Espera 2-3 minutos hasta que el estado sea "Running".

Paso 4: Conectarse por SSH

1 Obtener IP pública: En EC2 Console, copia la "Public IPv4 address"
2 Abrir terminal: Usa Git Bash, PowerShell, o terminal de Linux/Mac
3 Navegar a donde descargaste la key: 
cd /ruta/a/donde/descargaste
4 Cambiar permisos de la key (solo Linux/Mac): 
chmod 400 if0099-key.pem
5 Conectarse:
$ ssh -i "if0099-key.pem" ubuntu@TU_IP_PUBLICA

# Ejemplo: ssh -i "if0099-key.pem" ubuntu@54.123.45.67
6 Confirmar conexión:
ubuntu@ip:~$ whoami
ubuntu

ubuntu@ip:~$ uname -a
Linux ip-172-31-XX-XX 5.15.0-xxxx-generic #xx-Ubuntu SMP xx

🎉 ¡Conectado!

Ahora estás ejecutando comandos en una instancia Linux real en la nube de AWS.

Paso 5: APAGAR la Instancia (CRÍTICO)

⚠️ SIEMPRE APAGA CUANDO TERMINES

Una instancia encendida consume horas de tu Free Tier. APÁGALA cuando no la uses.

1 En EC2 Console: Selecciona tu instancia
2 Clic derecho: → Instance State → Stop
3 Confirmar: Haz clic en "Stop"
4 Verificar: El estado cambia a "Stopped"

✅ Instancia Apagada

La instancia NO generará costos mientras esté apagada. Los datos en el disco se mantienen.

Para Encender de Nuevo:

→ Instance State → Start
→ Esperar 1-2 minutos
→ Copiar NUEVA IP (puede cambiar)
→ Conectarse con la nueva IP

Comandos Básicos en EC2

Una vez conectado, practica estos comandos:

ubuntu@ip:~$ sudo apt update
(actualizar lista de paquetes)

ubuntu@ip:~$ sudo apt install htop -y
(instalar monitor de recursos)

ubuntu@ip:~$ htop
(ver uso de CPU, RAM)

ubuntu@ip:~$ free -h
(ver memoria disponible)

ubuntu@ip:~$ df -h
(ver espacio en disco)
