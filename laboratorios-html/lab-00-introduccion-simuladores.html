Cronograma Rubricas

Entorno de Laboratorio Virtual

En este curso utilizaremos VirtualBox para crear máquinas virtuales de Ubuntu Server 22.04 LTS. Este enfoque te proporcionará un entorno de servidor Linux real y completo, idéntico al usado en entornos de producción.

Ventajas: Entorno real de servidor, persistencia completa,Sin restricciones de tiempo, Ideal para aprender administración de sistemas.

Objetivos del Laboratorio

  • Instalar y configurar VirtualBox en tu computadora
  • Descargar e instalar Ubuntu Server 22.04 LTS en una máquina virtual
  • Configurar red y acceso SSH a la VM
  • Realizar configuración inicial del servidor
  • Verificar el funcionamiento de la VM

Paso 1: Instalar VirtualBox

¿Qué es VirtualBox?

VirtualBox es un software de virtualización x86 que permite ejecutar múltiples sistemas operativos simultáneamente. Es gratuito, de código abierto, y funciona en Windows, macOS, y Linux.

Actividad: Descargar e Instalar VirtualBox

1 Descargar VirtualBox: Visita el sitio oficial y descarga la versión para tu sistema operativo:

Descargar VirtualBox
2 Ejecutar el instalador: Abre el archivo descargado y sigue el asistente de instalación.
  • Acepta los términos del acuerdo de licencia
  • Mantén las opciones predeterminadas recomendadas
  • El instalador puede pedir reiniciar tu computadora
3 Verificar instalación: Abre VirtualBox desde el menú de aplicaciones. Deberías ver la interfaz principal con el botón "Nueva" para crear una VM.
4 Descargar Ubuntu Server: Descarga la ISO de Ubuntu Server 22.04 LTS:

Descargar Ubuntu Server 22.04 LTS

Nota: El archivo ISO pesa aproximadamente 3.6 GB. La descarga puede tomar tiempo según tu conexión.

Paso 2: Crear la Máquina Virtual

Actividad: Configurar una Nueva VM en VirtualBox

1 Crear nueva VM: En VirtualBox, haz clic en el botón "Nueva" (New).
2 Nombre y sistema operativo:
  • Nombre: Ubuntu-Server-IF0099
  • Carpeta de máquina: Elige una ubicación con suficiente espacio (mínimo 25 GB)
  • Tipo: Linux
  • Versión: Ubuntu (64-bit)
3 Memoria RAM: Asigna memoria a la VM.
  • Mínimo recomendado: 2048 MB (2 GB)
  • Óptimo: 4096 MB (4 GB) si tu computadora lo permite

Nota: La memoria RAM se comparte entre tu host y la VM. No asignes más del 50% de tu RAM total.

4 Disco duro: Crea un disco duro virtual.
  • Tipo de archivo: VDI (VirtualBox Disk Image)
  • Almacenamiento: Dinámicamente asignado
  • Tamaño: 25.00 GB (mínimo recomendado)
5 Resumen: Revisa la configuración y haz clic en "Finalizar". La VM aparecerá en el panel izquierdo de VirtualBox.

Paso 3: Configurar la VM

Actividad: Ajustes de Red y Sistema

1 Configurar red: Con la VM seleccionada, haz clic en "Configuración" → "Red".
  • Adaptador 1: Habilitado
  • Conectado a: NAT
  • Avanzado: Habilitar "Cable conectado"

NAT permite que la VM tenga acceso a Internet a través de la conexión de tu host.

2 Montar la ISO: En "Configuración" → "Almacenamiento":
  • Controlador: IDE Secundario
  • Haz clic en el icono del disco óptico vacío
  • Selecciona "Elegir un archivo de disco óptico"
  • Navega a donde descargaste la ISO de Ubuntu Server
  • Selecciona el archivo ubuntu-22.04.x-live-server-amd64.iso
3 Configurar portapapeles (opcional): Para poder copiar/pegar entre host y VM:
  • "Configuración" → "General" → "Portapapeles"
  • Selecciona "Bidireccional"
  • También puedes habilitar "Arrastrar y soltar" → "Bidireccional"

Paso 4: Instalar Ubuntu Server

Actividad: Instalación del Sistema Operativo

1 Iniciar la VM: Haz clic en "Iniciar" en VirtualBox. La VM arrancará desde la ISO.
2Pantalla de inicio: Selecciona "Try or Install Ubuntu Server" y presiona Enter.
3 Idioma: Selecciona tu idioma preferido y continúa.
4 Configuración de red: Ubuntu detectará y configurará automáticamente la red (usando DHCP).

Anota la dirección IP que se asigne (ej: 10.0.2.15).

5 Configurar proxy: Si no usas un proxy, deja esto en blanco y continúa.
6 Dirección del mirror: Selecciona el mirror más cercano a tu ubicación geográfica.
7 Almacenamiento: Selecciona "Usar todo el disco" para una configuración automática con LVM.
8 Perfil de usuario: Crea tu usuario:
  • Nombre: Tu nombre
  • Nombre de servidor: if0099-server
  • Nombre de usuario: if0099 (o tu preferencia)
  • Contraseña: Elige una contraseña segura y recuérdala
9 Actualizaciones automáticas: Selecciona "Sin actualizaciones automáticas" para este laboratorio (preferimos control manual).
10 Selección de software: Para este curso, NO selecciones ningún paquete adicional (OpenSSH se instalará manualmente después).
11 Instalación: El instalador procederá a instalar el sistema. Esto puede tomar varios minutos.
12 Reiniciar: Cuando se complete, haz clic en "Reiniciar ahora". La VM se reiniciará.

Paso 5: Configuración Inicial del Servidor

Actividad: Primeros Pasos en Ubuntu Server

1 Iniciar sesión: En la pantalla de login, ingresa tu nombre de usuario y contraseña creados durante la instalación.
2 Verificar el sistema: Ejecuta el comando para ver información del sistema: 
uname -a
3 Verificar versión de Ubuntu: 
cat /etc/os-release
4 Verificar conectividad de red: 
ping -c 4 google.com

Si recibes respuestas, tu VM tiene conexión a Internet.

5 Actualizar el sistema: Es una buena práctica actualizar los paquetes: 
sudo apt update
sudo apt upgrade -y

Nota: Ingresa tu contraseña cuando se solicite.

Paso 6: Habilitar Acceso SSH

¿Por qué SSH?

SSH (Secure Shell) te permite acceder a tu servidor de forma remota desde la terminal de tu computadora host. Esto es más cómodo que trabajar directamente en la ventana de VirtualBox.

Actividad: Instalar y Configurar SSH

1 Instalar OpenSSH Server: 
sudo apt install openssh-server -y
2 Verificar que SSH está ejecutándose: 
sudo systemctl status ssh

Deberías ver "active (running)" en verde.

3 Obtener la IP de la VM: 
ip addr show | grep inet

Busca la dirección en la interfaz que no es "lo" (loopback). Generalmente es algo como 10.0.2.15.

4 Conectarse desde el host: Abre una terminal en tu computadora (fuera de VirtualBox) y ejecuta: 
ssh tu_usuario@10.0.2.15

Reemplaza tu_usuario con el nombre de usuario que creaste y 10.0.2.15 con la IP de tu VM.

5 Aceptar fingerprint: La primera vez, verás un mensaje sobre fingerprint. Escribe yes para continuar.
6 Ingresar contraseña: Ingresa la contraseña de tu usuario en la VM.
7 ¡Éxito! Ahora estás conectado a tu VM via SSH. El prompt cambiará para mostrar que estás en el servidor remoto.

Paso 7: Crear una Snapshot

Snapshot: Punto de Restauración

Una snapshot captura el estado exacto de tu VM en un momento dado. Si algo sale mal en el futuro, puedes restaurar la snapshot en lugar de reinstalar todo.

Actividad: Crear Snapshot Inicial

1 Apagar la VM correctamente: Desde SSH o la consola de VirtualBox: 
sudo poweroff
2 Crear snapshot: En VirtualBox, con la VM seleccionada:
  • Haz clic en "Máquina" → "Tomar snapshot"
  • Nombre: Post-Instalación Base
  • Descripción: Ubuntu Server 22.04 LTS instalado, SSH habilitado, sistema actualizado
  • Haz clic en "Aceptar"
3 Verificar snapshot: La snapshot aparecerá en "Máquina" → "Snapshots". Puedes crear snapshots adicionales después de cada laboratorio.
