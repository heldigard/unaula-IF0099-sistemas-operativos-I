1. Comandos de Monitoreo de Procesos

ps - Process Status

Muestra una instantánea de los procesos actuales.

Variantes útiles:

ps aux              # Todos los procesos de todos los usuarios
ps aux | grep ssh   # Buscar procesos específicos
ps -ef              # Formato completo
ps -u usuario       # Procesos de un usuario específico
~ $ ps aux | head -10
USER PID %CPU %MEM VSZ RSS TTY STAT START TIME COMMAND
root 1 0.0 0.1 185432 6200 ? Ss 10:00 0:01 /sbin/init
root 2 0.0 0.0 0 0 ? S 10:00 0:00 [kthreadd]
💡 Interpretación: USER=usuario, PID=ID proceso, %CPU=uso CPU, %MEM=uso memoria, VSZ=memoria virtual, RSS=memoria física, STAT=estado

top - Monitor de Procesos en Tiempo Real

Muestra procesos en tiempo real con actualización automática.

top                 # Iniciar monitor
# Dentro de top:
q                   # Salir
k                   # Matar proceso (ingresar PID)
n                   # Cambiar número de procesos mostrados
M                   # Ordenar por uso de memoria
P                   # Ordenar por uso de CPU

htop - Monitor Interactivo Mejorado

Versión mejorada de top con interfaz visual.

sudo apt install htop    # Instalar si no está disponible
htop                     # Ejecutar
💡 Ventajas de htop: Navegación con flechas, matar procesos con F9, búsqueda con F3, árbol de procesos con F5

pgrep - Buscar Procesos por Nombre

pgrep ssh           # Buscar PID de procesos ssh
pgrep -l ssh        # Mostrar nombre también
pgrep -u root       # Procesos del usuario root
pgrep -x bash       # Coincidencia exacta

pidof - Obtener PID de un Programa

pidof apache2       # Obtener PID de apache2
pidof -x script.sh  # PID de un script

2. Gestión de Procesos

kill - Enviar Señales a Procesos

Envía señales para controlar procesos.

Señal Número Descripción
SIGHUP 1 Recargar configuración
SIGINT 2 Interrupción (Ctrl+C)
SIGTERM 15 Terminar graceful (por defecto)
SIGKILL 9 Matar forzosamente
SIGSTOP 19 Detener proceso
SIGCONT 18 Continuar proceso

Ejemplos:

kill 1234           # Enviar SIGTERM al PID 1234
kill -9 1234        # Matar forzosamente
kill -15 1234       # Terminar graceful
kill -HUP 1234      # Recargar configuración

killall - Matar por Nombre

killall firefox     # Matar todos los procesos firefox
killall -9 apache2  # Forzar cierre de apache2
killall -u usuario  # Matar procesos de un usuario

⚠️ Precaución

killall mata TODOS los procesos con ese nombre. Usa con cuidado en sistemas de producción.

pkill - Matar por Patrón

pkill ssh           # Matar todos los procesos ssh
pkill -f "python app.py"  # Matar por comando completo
pkill -u usuario    # Matar todos los procesos de un usuario

nice y renice - Prioridad de Procesos

Valores de nice: -20 (máxima prioridad) a 19 (mínima prioridad)

# Iniciar proceso con prioridad baja
nice -n 10 ./script.sh

# Iniciar con prioridad alta (requiere root)
sudo nice -n -5 ./script.sh

# Cambiar prioridad de proceso existente
renice 10 -p 1234   # Cambiar PID 1234 a nice 10
renice -5 -u usuario # Cambiar prioridad de todos los procesos de un usuario

3. Gestión de Servicios con systemctl

Estados de Servicios

systemctl status ssh        # Ver estado del servicio SSH
systemctl is-active ssh     # ¿Está activo?
systemctl is-enabled ssh    # ¿Está habilitado al inicio?

Control de Servicios

sudo systemctl start ssh     # Iniciar servicio
sudo systemctl stop ssh      # Detener servicio
sudo systemctl restart ssh   # Reiniciar servicio
sudo systemctl reload ssh    # Recargar configuración

Habilitar/Deshabilitar al Inicio

sudo systemctl enable ssh    # Habilitar al inicio
sudo systemctl disable ssh   # Deshabilitar al inicio

Listar Servicios

systemctl list-units --type=service           # Servicios activos
systemctl list-units --type=service --state=running  # Solo en ejecución
systemctl list-unit-files --type=service      # Todos los servicios
💡 Servicios comunes: ssh, apache2, nginx, mysql, postgresql, cron

4. Procesos en Windows con PowerShell

Comandos Equivalentes

Linux PowerShell Descripción
ps aux Get-Process Listar procesos
kill Stop-Process Matar proceso
top Get-Process | Sort-Object CPU -Descending Procesos por CPU

Ejemplos PowerShell

Get-Process                    # Listar todos los procesos
Get-Process | Sort-Object CPU -Descending | Select-Object -First 10  # Top 10 por CPU
Get-Process -Name chrome       # Procesos específicos
Stop-Process -Name notepad     # Matar proceso
Stop-Process -ID 1234 -Force   # Forzar cierre
Get-Service                    # Listar servicios
Start-Service -Name sshd       # Iniciar servicio
Stop-Service -Name sshd        # Detener servicio

5. Scripts de Monitoreo

Script 1: Monitor de Procesos

Crea un script que monitorea procesos zombies y consume muchos recursos.

#!/bin/bash
# monitor_procesos.sh - Script de monitoreo

echo "=== Monitor de Procesos ==="
echo "Fecha: $(date)"
echo ""

echo "Top 5 procesos por CPU:"
ps aux --sort=-%cpu | head -6

echo ""
echo "Top 5 procesos por Memoria:"
ps aux --sort=-%mem | head -6

echo ""
echo "Procesos zombies:"
ps aux | grep 'Z' | grep -v grep

echo ""
echo "Procesos del usuario actual:"
ps -u $(whoami) --sort=-%cpu | head -10

Para ejecutar:

chmod +x monitor_procesos.sh
./monitor_procesos.sh

Script 2: Alerta de Recursos

#!/bin/bash
# alerta_recursos.sh - Alerta cuando CPU > 80%

CPU_USAGE=$(top -bn1 | grep "Cpu(s)" | awk '{print $2}' | cut -d'%' -f1)

if (( $(echo "$CPU_USAGE > 80" | bc -l) )); then
    echo "⚠️ ALERTA: Uso de CPU alto: ${CPU_USAGE}%"
    echo "Procesos que consumen más CPU:"
    ps aux --sort=-%cpu | head -5
else
    echo "✅ Uso de CPU normal: ${CPU_USAGE}%"
fi
