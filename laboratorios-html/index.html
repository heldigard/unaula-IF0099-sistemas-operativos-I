📘 Bienvenido a los Laboratorios

Esta sección contiene guías prácticas para complementar las clases teóricas. Los laboratorios están diseñados para realizarse en orden, ya que cada uno construye sobre los conceptos del anterior.

⚠️ Importante: Uso de Recursos

Los laboratorios 00-02 usan simuladores en línea (GRATIS). Los laboratorios AWS requieren una cuenta de AWS con tarjeta de crédito, pero pueden ser completamente GRATIS si sigues las instrucciones cuidadosamente.

Fundamentos de Linux

Laboratorios introductorios para familiarizarse con la línea de comandos de Linux usando simuladores en línea gratuitos.

LAB 00

Introducción a Simuladores de Linux

Conoce JSLinux, DistroTest y otros simuladores de Linux en línea. No requieren instalación.

⏱️ 90 min 📊 Introductorio
LAB 01

Comandos Básicos de Linux

Aprende a navegar el sistema de archivos, crear archivos y directorios, y usar comandos esenciales.

⏱️ 90 min 📊 Introductorio Disponible
LAB 02

Permisos y Usuarios

Entiende el sistema de permisos de Linux, chmod, chown y gestión de usuarios.

⏱️ 90 min 📊 Intermedio Disponible

AWS EC2 - Computación en la Nube AWS

Laboratorios para usar Amazon EC2 con el Free Tier. Requieren tarjeta de crédito pero pueden ser completamente gratis si se siguen las instrucciones.

🚨 Antes de comenzar los laboratorios AWS

  • Tarjeta de crédito internacional (requerida por AWS)
  • Compromiso de APAGAR siempre las instancias
  • Configurar alertas de presupuesto
AWS 01

Introducción a EC2 Gratis

Crea tu cuenta AWS gratuita y lanza tu primera instancia EC2 sin costos. Aprende a conectarte por SSH.

⏱️ 120 min 📊 Introductorio Disponible
AWS 02

Procesos en EC2

Práctica con procesos reales: fork, exec, señales y monitoreo en EC2.

⏱️ 90 min 📊 Intermedio Próximamente
AWS 03

Gestión de Memoria

Explora la memoria real en EC2, swap, y herramientas de monitoreo.

⏱️ 90 min 📊 Intermedio Próximamente
AWS 04

Sistemas de Archivos

Trabaja con sistemas de archivos reales, particiones y montajes en EC2.

⏱️ 120 min 📊 Avanzado Próximamente

📋 Recomendaciones

  1. Completa los laboratorios en orden: Cada laboratorio asume conocimientos del anterior.
  2. Usa los simuladores primero: Los Labs 00-02 son perfectos para empezar sin costos.
  3. Cuidado con AWS: Solo crea instancias EC2 cuando estés listo para usarlas.
  4. APAGA TODO: Nunca dejes instancias EC2 encendidas cuando no las uses.
  5. Documenta tu trabajo: Toma notas de lo que aprendes en cada laboratorio.
