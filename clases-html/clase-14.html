Teoría: IIS y Arquitectura

¿Qué es IIS?

Internet Information Services (IIS) es el servidor web de Microsoft para Windows Server. Es una plataforma extensible y modular para hospedar sitios web y servicios.

Características Principales

  • Servidor web nativo de Windows
  • Integración con Active Directory
  • Soporte para ASP.NET, PHP, Python
  • Interfaz gráfica (IIS Manager)
  • PowerShell para automatización
  • FTP, SMTP, WebDAV integrados

Casos de Uso

  • Aplicaciones ASP.NET Core
  • Intranets corporativas
  • Web APIs REST
  • Hosting de aplicaciones empresariales
  • Sitios web con integración Windows

Componentes Clave

1. HTTP.SYS

  • Driver del kernel que escucha solicitudes HTTP
  • Maneja colas de solicitudes
  • Procesa respuestas de caché
  • Proporciona seguridad a nivel de kernel

2. Application Pools

  • Aíslan aplicaciones entre sí
  • Cada pool tiene su propio worker process (w3wp.exe)
  • Permiten configuración independiente
  • Previenen que una aplicación afecte a otras

Instalación de IIS

Requisitos previos:
  • VM con Windows Server 2022
  • Usuario con privilegios de Administrador
  • Conexión a Internet

Instalación con PowerShell (Recomendado)

# Instalar IIS con roles básicos
Install-WindowsFeature -name Web-Server -IncludeManagementTools

# Verificar instalación
Get-WindowsFeature -Name Web-Server

Verificar instalación

# Verificar que IIS está corriendo
Get-Service W3SVC

# Probar desde el navegador
# http://localhost (deberías ver "IIS Windows Server" page)
Ubicación de archivos:
  • C:\inetpub\wwwroot - Document root por defecto
  • C:\Windows\System32\inetsrv\config - Configuración
  • C:\inetpub\logs\LogFiles - Logs

Crear un Sitio Web

Crear con PowerShell

# Crear directorio
New-Item -Path "C:\inetpub\Site1" -ItemType Directory -Force

# Crear archivo HTML
Set-Content -Path "C:\inetpub\Site1\index.html" -Value @"
<h1>Bienvenido a Site 1 en IIS</h1>
"@

# Crear App Pool
New-WebAppPool -Name "Site1Pool" -Force

# Crear sitio web
New-Website -Name "Site1" `
    -PhysicalPath "C:\inetpub\Site1" `
    -ApplicationPool "Site1Pool" `
    -Port 8080 `
    -Force

Configurar HTTPS en IIS

Crear certificado self-signed

# Crear certificado
$cert = New-SelfSignedCertificate `
    -DnsName "site1.local" `
    -CertStoreLocation "cert:\LocalMachine\My"

Asignar al sitio (IIS Manager)

  1. Abrir IIS Manager
  2. Seleccionar Site1
  3. Clic en "Bindings..."
  4. Add → Type: https, Port: 4433
  5. Seleccionar certificado site1.local
