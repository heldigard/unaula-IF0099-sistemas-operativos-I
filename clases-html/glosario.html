Glosario de Sistemas Operativos

Este glosario contiene las abreviaciones y terminos tecnicos utilizados en el curso. Consultalo cuando encuentres un termino que no conozcas.

A
ACL
Access Control List (Lista de Control de Acceso) - Lista que especifica que usuarios o procesos tienen permiso para acceder a objetos del sistema.
AD
Active Directory - Servicio de directorio de Microsoft para gestionar usuarios, equipos y recursos en redes Windows.
API
Application Programming Interface (Interfaz de Programacion de Aplicaciones) - Conjunto de funciones que permiten a los programas comunicarse con el SO.
AWS
Amazon Web Services - Plataforma de servicios en la nube de Amazon, utilizada para practicas con EC2.
B
Bash
Bourne Again Shell - Interprete de comandos por defecto en la mayoria de distribuciones Linux.
C
CLI
Command Line Interface (Interfaz de Linea de Comandos) - Metodo de interaccion con el sistema mediante comandos de texto.
CPU
Central Processing Unit (Unidad Central de Procesamiento) - Componente principal que ejecuta instrucciones de los programas.
E
E/S o I/O
Entrada/Salida (Input/Output) - Comunicacion entre el procesador y dispositivos perifericos (teclado, disco, pantalla).
EC2
Elastic Compute Cloud - Servicio de maquinas virtuales en la nube de Amazon Web Services.
EXT4
Fourth Extended Filesystem - Sistema de archivos por defecto en muchas distribuciones Linux.
F
FS
File System (Sistema de Archivos) - Metodo para organizar y almacenar datos en dispositivos de almacenamiento.
FTP
File Transfer Protocol - Protocolo para transferencia de archivos en redes.
G
GPO
Group Policy Object - Objeto de politica de grupo en Active Directory para gestionar configuraciones.
GUI
Graphical User Interface (Interfaz Grafica de Usuario) - Metodo de interaccion visual con el sistema.
H
Hardening
Proceso de asegurar un sistema reduciendo su superficie de vulnerabilidad.
HTTP/HTTPS
Hypertext Transfer Protocol (Secure) - Protocolos para transferencia de paginas web.
I
IIS
Internet Information Services - Servidor web de Microsoft para Windows Server.
IPC
Inter-Process Communication (Comunicacion Entre Procesos) - Mecanismos que permiten a los procesos intercambiar datos.
ISO
Imagen de disco optico - Archivo que contiene una copia exacta de un sistema de archivos, usado para instalar SO.
J
Journaling
Tecnica de sistemas de archivos que registra cambios antes de aplicarlos para prevenir perdida de datos.
K
Kernel
Nucleo del sistema operativo - componente central que gestiona recursos del hardware y proporciona servicios a los programas.
L
LTS
Long Term Support (Soporte a Largo Plazo) - Version de software con soporte extendido, como Ubuntu 22.04 LTS.
LVM
Logical Volume Manager - Sistema para gestionar espacio de disco de forma flexible en Linux.
M
Mutex
Mutual Exclusion (Exclusion Mutua) - Mecanismo de sincronizacion que evita acceso concurrente a recursos compartidos.
N
NTFS
New Technology File System - Sistema de archivos nativo de Windows con soporte para permisos ACL.
P
PCB
Process Control Block (Bloque de Control de Proceso) - Estructura de datos que almacena informacion de un proceso.
PID
Process Identifier - Numero unico asignado a cada proceso en ejecucion.
PowerShell
Shell de linea de comandos y lenguaje de scripting de Microsoft para administracion de Windows.
R
RAID
Redundant Array of Independent Disks - Tecnica para combinar multiples discos para mejorar rendimiento o redundancia.
RAM
Random Access Memory (Memoria de Acceso Aleatorio) - Memoria volatil donde se cargan los programas en ejecucion.
S
Semaforo
Variable especial para controlar acceso a recursos compartidos en programacion concurrente.
Shell
Interprete de comandos que permite a los usuarios interactuar con el sistema operativo.
SO
Sistema Operativo - Software que gestiona el hardware y proporciona servicios a los programas.
SSH
Secure Shell - Protocolo para acceso remoto seguro a servidores.
SSL/TLS
Secure Sockets Layer / Transport Layer Security - Protocolos para comunicaciones cifradas.
Swap
Espacio en disco usado como extension de la memoria RAM cuando esta se agota.
T
TLB
Translation Lookaside Buffer - Cache del procesador para traducir direcciones virtuales a fisicas.
Thrashing
Condicion donde el sistema pasa mas tiempo paginando que ejecutando programas.
V
VM
Virtual Machine (Maquina Virtual) - Software que emula un sistema de computo completo.
VirtualBox
Software de virtualizacion gratuito de Oracle para crear maquinas virtuales.
