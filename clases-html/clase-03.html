1. ¿Qué es Windows Server?

Windows Server es un sistema operativo diseñado para servidores - máquinas que proveen servicios a otros computadores (clientes) en una red.

🖥️ Windows Desktop

Diseñado para: Usuarios individuales

Uso típico:

  • Ofimática (Word, Excel)
  • Navegación web
  • Juegos
  • Desarrollo personal

Ediciones: Home, Pro, Enterprise

Interfaz: Orientada a consumo

🏢 Windows Server

Diseñado para: Servicios de red

Uso típico:

  • Servidor de archivos (SMB)
  • Servidor web (IIS)
  • Active Directory
  • Servidor de bases de datos

Ediciones: Essentials, Standard, Datacenter

Interfaz: Orientada a administración

🎯 Casos de uso de Windows Server

Servicio Descripción Ejemplo
AD DS Active Directory Domain Services Autenticación centralizada en empresas
File Server Compartición de archivos via SMB Carpetas compartidas departamentales
IIS Internet Information Services Hospedaje de aplicaciones ASP.NET
DHCP Dynamic Host Configuration Protocol Asignación automática de IPs
DNS Domain Name System Resolución de nombres en red interna

💡 Dato clave: Windows Server 2022 está basado en Windows 10, pero con roles y características orientadas a servidores. No está diseñado para uso personal.

2. Windows Server vs Windows Desktop Teoría10 min

Diferencias técnicas principales

Característica Windows Desktop Windows Server
Conexiones simultáneas 1-2 usuarios (RDP limitado) Ilimitadas (con licencias)
RAM máxima Limitada por edición Hasta 24 TB (Datacenter)
Roles de servidor No disponibles AD DS, DHCP, DNS, IIS, etc.
Interfaz Desktop completo Opción Server Core (sin GUI)
Actualizaciones Windows Update automático Controladas por administrador
Precio Incluido con PC Por licencia + CALs

💰 Modelo de licenciamiento

Windows Server: Requiere dos tipos de licencias:

  • Licencia del servidor: Por núcleo de procesador
  • CAL (Client Access License): Por usuario o dispositivo que accede

⚠️ Importante: Windows Server NO es gratis. Para fines educativos, puedes usar evaluaciones de 180 días o licencias académicas.

4. Configuración Inicial del Servidor Práctica15 min

Paso 1: Cambiar nombre del servidor

# Opción 1: Server Manager
Server Manager → Local Server → Properties → COMPUTER NAME
→ [Change] → Nuevo nombre: WS2022-01 → [OK] → Reiniciar

# Opción 2: PowerShell (Recomendado)
Rename-Computer -NewName "WS2022-01" -Restart
# Para reiniciar manualmente:
Restart-Computer

Paso 2: Configurar red IP estática

# Ver configuración actual
Get-NetIPAddress

# Configurar IP estática (reemplazar con tus datos)
New-NetIPAddress `
    -InterfaceAlias "Ethernet" `
    -IPAddress 192.168.1.100 `
    -PrefixLength 24 `
    -DefaultGateway 192.168.1.1

# Configurar DNS
Set-DnsClientServerAddress `
    -InterfaceAlias "Ethernet" `
    -ServerAddresses 192.168.1.1, 8.8.8.8

# Verificar configuración
ipconfig
ping 8.8.8.8

Paso 3: Configurar actualizaciones automáticas

# Abrir Settings
sconfig

# Menu:
8. Windows Update Settings
→ A (Automatic)
→ 3 (Every day)
→ 03:00 (3 AM)

# Volver al menú principal
15. Exit

Paso 4: Habilitar Remote Desktop

# Via PowerShell
Set-ItemProperty -Path 'HKLM:\System\CurrentControlSet\Control\Terminal Server' `
    -Name "fDenyTSConnections" -Value 0

# Habilitar en firewall
Enable-NetFirewallRule -DisplayGroup "Remote Desktop"

# Verificar estado
Get-WmiObject -class "Win32_TSGeneralSetting" -Namespace root\cimv2\terminalservices

⚠️ Seguridad: Solo habilita RDP si es necesario. Usa VPN y contraseñas fuertes. Considera cambiar el puerto por defecto (3389).

5. PowerShell Básico Práctica25 min

¿Qué es PowerShell?

PowerShell es un shell de línea de comandos y lenguaje de scripting diseñado para administración de sistemas. A diferencia de CMD:

  • Basado en objetos (.NET), no texto
  • Comandos consistentes (Verb-Noun)
  • Pipeline poderoso
  • Orientado a administración, no usuario final

Abrir PowerShell

# Opción 1: Buscar "PowerShell" en Start Menu
# Opción 2: Win + X → Windows PowerShell
# Opción 3: Server Manager → Tools → PowerShell

Comandos básicos equivalentes a Linux

Tarea Linux PowerShell
Listar archivos ls Get-ChildItem (alias: ls, dir)
Directorio actual pwd Get-Location (alias: pwd)
Cambiar directorio cd Set-Location (alias: cd)
Ver procesos ps Get-Process
Ver servicios systemctl status Get-Service
Crear archivo touch New-Item -ItemType File
Crear directorio mkdir New-Item -ItemType Directory
Copiar archivo cp Copy-Item
Mover archivo mv Move-Item
Borrar archivo rm Remove-Item
Ver contenido cat Get-Content
Buscar en texto grep Select-String

Ejercicio: Navegación y archivos

# 1. Ver ubicación actual
Get-Location

# 2. Listar archivos
Get-ChildItem

# 3. Ir a C:\ (raíz)
Set-Location C:\

# 4. Crear directorio de proyecto
New-Item -ItemType Directory -Path "C:\ProyectoSO"

# 5. Entrar al directorio
Set-Location "C:\ProyectoSO"

# 6. Crear archivo de texto
"Mi primer archivo en PowerShell" | Out-File "notas.txt"

# 7. Ver contenido del archivo
Get-Content "notas.txt"

# 8. Crear subdirectorios
New-Item -ItemType Directory -Path "Documentos"
New-Item -ItemType Directory -Path "Scripts"

# 9. Copiar archivo
Copy-Item "notas.txt" "Documentos\notas-copia.txt"

# 10. Mover archivo
Move-Item "notas.txt" "Documentos\notas-original.txt"

# 11. Listar estructura
Get-ChildItem -Recurse

Trabajo con procesos

# Ver todos los procesos
Get-Process

# Buscar proceso específico
Get-Process | Where-Object {$_.Name -like "svchost"}

# Ver procesos con alto uso de CPU
Get-Process | Where-Object {$_.CPU -gt 10} | Sort-Object CPU -Descending

# Matar proceso (cuidado)
Stop-Process -Name "notepad" -Force

# Matar por PID
Stop-Process -Id 1234 -Force

Trabajo con servicios

# Ver todos los servicios
Get-Service

# Ver servicios corriendo
Get-Service | Where-Object {$_.Status -eq "Running"}

# Buscar servicio específico
Get-Service -Name "Spooler"

# Iniciar servicio
Start-Service -Name "Spooler"

# Detener servicio
Stop-Service -Name "Spooler" -Force

# Reiniciar servicio
Restart-Service -Name "Spooler"

Obtener ayuda

# Ayuda de comando
Get-Help Get-Process

# Ayuda con ejemplos
Get-Help Get-Process -Examples

# Ayuda online (abre navegador)
Get-Help Get-Process -Online

# Actualizar ayuda (requiere admin)
Update-Help

6. Comparación: Linux vs PowerShell Práctica10 min

Tabla de equivalencias

Categoría Linux PowerShell
Navegación pwd, ls, cd Get-Location, Get-ChildItem, Set-Location
Archivos touch, mkdir, cp, mv, rm New-Item, Copy-Item, Move-Item, Remove-Item
Texto cat, grep, head, tail, less Get-Content, Select-String, Select-Object
Procesos ps, top, kill Get-Process, Stop-Process
Servicios systemctl status/stop/start Get-Service, Stop-Service, Start-Service
Permisos chmod, chown icacls, Get-Acl, Set-Acl
Red ifconfig, ping, ssh Get-NetIPAddress, Test-Connection, Enter-PSSession
Paquetes apt, yum, dnf Get-WindowsFeature, Install-WindowsFeature

Diferencias filosóficas

🐧 Linux

  • "Todo es un archivo" - Dispositivos, procesos, sockets
  • Basado en texto - Los comandos manejan strings
  • Pipelines de texto - | conecta stdout a stdin
  • Comandos cortos - ls, cd, cp, mv
  • Config en texto - Archivos .conf en /etc

🪟 PowerShell

  • "Todo es un objeto" - Objetos .NET estructurados
  • Basado en objetos - Los comandos manejan propiedades
  • Pipelines de objetos - | pasa objetos completos
  • Verbos descriptivos - Get-ChildItem, Set-Location
  • Config en Registry - HKLM:\, HKCU:\

Ejemplo: Pipeline en Linux vs PowerShell

# LINUX - Pipeline de TEXTO
# Listar procesos, buscar "chrome", tomar top 5
ps aux | grep chrome | head -5
# Resultado: Líneas de texto

# POWERSHELL - Pipeline de OBJETOS
# Listar procesos, filtrar "chrome", ordenar por CPU, tomar top 5
Get-Process | Where-Object {$_.Name -like "*chrome*"} |
               Sort-Object CPU -Descending |
               Select-Object -First 5
# Resultado: Objetos de proceso con propiedades accesibles

💡 Ventaja de objetos: En PowerShell, puedes acceder a propiedades específicas del objeto resultado. Por ejemplo: (Get-Process chrome).CPU te da el tiempo de CPU directamente.

7. Actividad Práctica

🎯 Actividad: Configuración de Windows Server 2022

Tipo: Práctica obligatoria

Duración: Fuera de clase (2 horas estimadas)

Entregable: Script PowerShell + capturas de pantalla

Requisitos:

  1. Crear una VM Windows Server 2022 en VirtualBox
  2. Configurar nombre de servidor: WS-[TuApellido]
  3. Configurar IP estática en red Host-Only
  4. Crear un script PowerShell que automatice tareas comunes

Script PowerShell requerido:

Nombre: configurar_servidor.ps1

# Script: configurar_servidor.ps1
# Autor: [Tu nombre]
# Fecha: 2026-02-10
# Descripción: Configuración inicial de Windows Server

# 1. Mostrar información del sistema
Write-Host "=== Información del Sistema ===" -ForegroundColor Cyan
Get-ComputerInfo | Select-Object OsName, WindowsVersion, CsName

# 2. Crear estructura de directorios
Write-Host "`n=== Creando directorios ===" -ForegroundColor Green
$dirs = @("C:\ProyectoSO\Documentos", "C:\ProyectoSO\Scripts", "C:\ProyectoSO\Logs")
foreach ($dir in $dirs) {
    New-Item -ItemType Directory -Path $dir -Force | Out-Null
    Write-Host "Creado: $dir"
}

# 3. Crear archivo de registro
Write-Host "`n=== Creando archivo de logs ===" -ForegroundColor Green
$logFile = "C:\ProyectoSO\Logs\config_$(Get-Date -Format 'yyyyMMdd').log"
"Configuración completada: $(Get-Date)" | Out-File $logFile
Write-Host "Log creado: $logFile"

# 4. Mostrar procesos con alto uso de CPU
Write-Host "`n=== Top 5 procesos por CPU ===" -ForegroundColor Yellow
Get-Process | Sort-Object CPU -Descending | Select-Object -First 5 |
    Format-Table Name, CPU, Id -AutoSize

# 5. Mostrar servicios corriendo
Write-Host "`n=== Servicios en ejecución ===" -ForegroundColor Yellow
Get-Service | Where-Object {$_.Status -eq "Running"} |
    Select-Object -First 10 |
    Format-Table Name, Status, DisplayName -AutoSize

Write-Host "`n=== Script completado ===" -ForegroundColor Green

Capturas de pantalla requeridas:

  • Server Manager mostrando nombre del servidor
  • PowerShell ejecutando el script
  • Salida del script (directorios creados, log, top procesos)
  • Configuración de red (ipconfig)
