Task Manager (Administrador de Tareas)

Task Manager es la herramienta básica para monitorear procesos en Windows

Cómo abrir Task Manager:

  • Ctrl + Shift + Esc - Atajo directo
  • Ctrl + Alt + Del → Task Manager
  • Clic derecho en barra de tareas → Task Manager
  • taskmgr en Ejecutar (Win + R)

Pestañas principales de Task Manager

Pestaña Descripción
Processes Lista de procesos en ejecución con PID, CPU, memoria
Performance Gráficos de CPU, memoria, disco, red
App history Historial de uso de recursos por aplicación
Startup Programas que se inician con Windows
Users Usuarios conectados y sus procesos
Details Vista detallada con PID y más columnas
Services Servicios del sistema con estado

Operaciones comunes:

  • End Task: Terminar proceso seleccionado
  • End Process Tree: Terminar proceso y sus hijos
  • Set Priority: Cambiar prioridad (Realtime, High, Normal, Low)
  • Analyze Wait Chain: Ver procesos que están esperando
  • Create Dump File: Crear volcado de memoria del proceso
⚠️ Precaución:
  • No termines procesos del sistema (System, csrss.exe, wininit.exe)
  • Terminar procesos críticos puede causar inestabilidad
  • Usa "End Task" solo cuando sea necesario

Process Explorer - Herramienta Avanzada

Process Explorer es una herramienta de Sysinternals que ofrece más detalles que Task Manager

Características de Process Explorer:

Ventajas sobre Task Manager

  • Árbol de procesos padre-hijo
  • Manejadores (handles) abiertos
  • DLLs cargadas por proceso
  • Información de threads
  • Propiedades detalladas
  • Búsqueda en línea de procesos
  • Verificar firma de archivos

Funciones útiles

  • Find Handle: Buscar qué archivo/DLL tiene abierto
  • Suspend/Resume: Pausar/reanudar proceso
  • Restart: Reiniciar proceso (como Explorer)
  • Run as: Ejecutar como otro usuario
  • Properties: Ver propiedades detalladas

Descargar Process Explorer:

  • Sitio: Microsoft Docs - Process Explorer
  • Portátil: No requiere instalación
  • Integración: Puede reemplazar Task Manager
Tip: Para reemplazar Task Manager con Process Explorer: 
Options → Replace Task Manager

PowerShell para Gestión de Procesos

PowerShell proporciona cmdlets potentes para gestionar procesos

Cmdlets principales de procesos:

Cmdlet Descripción Ejemplo
Get-Process Listar procesos Get-Process
Stop-Process Terminar proceso Stop-Process -Id 1234
Start-Process Iniciar proceso Start-Process notepad.exe
Wait-Process Esperar a que termine Wait-Process -Id 1234
Debug-Process Adjuntar depurador Debug-Process -Id 1234

Ver procesos con Get-Process:

# Listar todos los procesos
Get-Process

# Ver proceso específico por ID
Get-Process -Id 1234

# Ver proceso por nombre
Get-Process -Name notepad

# Filtrar por nombre con comodín
Get-Process -Name "*fire*"

# Ordenar por uso de CPU
Get-Process | Sort-Object CPU -Descending | Select-Object -First 10

# Ordenar por uso de memoria
Get-Process | Sort-Object WorkingSet -Descending | Select-Object -First 10

Terminar procesos con Stop-Process:

# Terminar por ID
Stop-Process -Id 1234

# Terminar por nombre
Stop-Process -Name notepad

# Forzar terminación
Stop-Process -Id 1234 -Force

# Terminar múltiples procesos
Get-Process -Name "*temp*" | Stop-Process

Propiedades útiles de Process:

# Ver propiedades de un proceso
Get-Process -Name notepad | Format-List *

# Propiedades comunes
Get-Process | Select-Object Id, Name, CPU, WorkingSet, Path

# Formatear salida como tabla
Get-Process | Format-Table Name, Id, CPU, WorkingSet -AutoSize

PowerShell para Gestión de Servicios

PowerShell permite administrar servicios de forma eficiente

Cmdlets principales de servicios:

Cmdlet Descripción Ejemplo
Get-Service Listar servicios Get-Service
Start-Service Iniciar servicio Start-Service Spooler
Stop-Service Detener servicio Stop-Service Spooler
Restart-Service Reiniciar servicio Restart-Service Spooler
Suspend-Service Pausar servicio Suspend-Service Winmgmt
Resume-Service Reanudar servicio Resume-Service Winmgmt
Set-Service Configurar servicio Set-Service Spooler -StartupType Automatic
New-Service Crear servicio New-Service -Name "MiServicio" ...

Ejemplos de gestión de servicios:

# Listar todos los servicios
Get-Service

# Ver servicio específico
Get-Service -Name Spooler

# Ver servicios ejecutándose
Get-Service | Where-Object Status -eq "Running"

# Ver servicios detenidos
Get-Service | Where-Object Status -eq "Stopped"

# Iniciar un servicio
Start-Service -Name Spooler

# Detener un servicio
Stop-Service -Name Spooler

# Reiniciar un servicio
Restart-Service -Name Spooler

# Ver propiedades de servicio
Get-Service Spooler | Format-List *

Tipos de inicio (StartupType):

# Automatic - Inicio automático
Set-Service -Name Spooler -StartupType Automatic

# Manual - Inicio manual
Set-Service -Name Spooler -StartupType Manual

# Disabled - Deshabilitado
Set-Service -Name Spooler -StartupType Disabled

# AutomaticDelayedStart - Automático con retraso
Set-Service -Name Spooler -StartupType AutomaticDelayedStart

sc.exe - Crear y Gestionar Servicios

sc.exe es una herramienta de línea de comandos para gestionar servicios

Diferencia entre sc.exe y cmdlet de PowerShell:

  • sc.exe: Herramienta nativa de Windows, más compatible con scripts antiguos
  • PowerShell: Más moderno, orientado a objetos, mejor para scripts nuevos

Comandos sc.exe principales:

Comando Descripción Ejemplo
sc query Consultar estado de servicio sc query Spooler
sc start Iniciar servicio sc start Spooler
sc stop Detener servicio sc stop Spooler
sc create Crear nuevo servicio sc create MiServicio ...
sc delete Eliminar servicio sc delete MiServicio
sc config Configurar servicio sc config Spooler start=auto
sc qc Query configuration sc qc Spooler

Crear un servicio simple con sc.exe:

# Sintaxis básica
sc create [nombre] binPath= "[ruta-ejecutable]" [opciones]

# Ejemplo: Crear servicio para una aplicación
sc create MiServicio binPath= "C:\MiApp\app.exe" start= auto

# Ejemplo: Servicio con descripción
sc create MiServicio ^
    binPath= "C:\MiApp\app.exe" ^
    start= auto ^
    DisplayName= "Mi Servicio Personalizado" ^
    depend= Tcpip

# Configurar tipo de inicio
sc config MiServicio start= demand

# Iniciar el servicio
sc start MiServicio

# Verificar estado
sc query MiServicio

# Eliminar servicio (debe estar detenido)
sc stop MiServicio
sc delete MiServicio
⚠️ Nota importante sobre sc.exe:
  • En sc.exe, el espacio después del signo igual es OBLIGATORIO: binPath= "..."
  • Servicios necesitan ejecutable con formato de servicio válido
  • No todos los executables pueden funcionar como servicio
  • Para aplicaciones normales, usar NSSM (Non-Sucking Service Manager)

Tipos de inicio con sc.exe:

start= boot     - Controladores de inicio
start= system   - Controladores de sistema
start= auto     - Automático
start= demand   - Manual
start= disabled - Deshabilitado

Práctica Guiada

Actividad 1: Explorar Task Manager

Tiempo: 10 minutos

  1. Abre Task Manager (Ctrl + Shift + Esc)
  2. Ve a la pestaña "Processes"
  3. Identifica el proceso con mayor uso de CPU
  4. Identifica el proceso con mayor uso de memoria
  5. Ve a la pestaña "Performance" y observa los gráficos
  6. Ve a "Details" y agrega la columna "PID"

Actividad 2: PowerShell - Listar y filtrar procesos

Tiempo: 15 minutos

  1. Abre PowerShell como administrador
  2. Lista todos los procesos: Get-Process
  3. Busca un proceso específico: Get-Process -Name explorer
  4. Ordena por CPU: Get-Process | Sort-Object CPU -Descending | Select-Object -First 10
  5. Ordena por memoria: Get-Process | Sort-Object WorkingSet -Descending | Select-Object -First 10
  6. Ver propiedades de un proceso: Get-Process -Id [PID] | Format-List *

Actividad 3: PowerShell - Gestión de servicios

Tiempo: 15 minutos

  1. Ver todos los servicios: Get-Service
  2. Ver servicios ejecutándose: Get-Service | Where-Object Status -eq "Running"
  3. Ver detalles del servicio Spooler: Get-Service Spooler | Format-List *
  4. Ver el tipo de inicio: Get-Service Spooler | Select-Object StartType
  5. Ver si Print Spooler está habilitado: Get-Service Spooler | Select-Object Status, StartType

Actividad 4: sc.exe - Crear un servicio simple

Tiempo: 15 minutos

  1. Abre CMD o PowerShell como administrador
  2. Verifica un servicio existente: sc query Spooler
  3. Ver configuración: sc qc Spooler
  4. Intenta crear un servicio de prueba: sc create Prueba binPath= "C:\Windows\System32\calc.exe" start= demand
  5. Intenta iniciarlo: sc start Prueba
  6. Observa el resultado (es normal que falle)
  7. Elimina el servicio: sc delete Prueba

Nota: Calc.exe no está diseñado como servicio, por lo que fallará. El propósito es practicar los comandos.

Entregable de la Clase

Script: gestion_procesos.ps1

Descripción: Script en PowerShell que muestra información de procesos y servicios

Requisitos:

  • Mostrar top 5 procesos por CPU
  • Mostrar top 5 procesos por memoria
  • Mostrar fecha y hora del reporte
  • Mostrar servicios que están ejecutándose
  • Guardar reporte en archivo con timestamp

Estructura sugerida:

# gestion_procesos.ps1
# Script de gestión de procesos y servicios en Windows

# Fecha y hora
$fecha = Get-Date -Format "yyyy-MM-dd HH:mm:ss"
$archivo = "reporte_$(Get-Date -Format 'yyyyMMdd_HHmmss').txt"

# Crear reporte
$contenido = @"
=== REPORTE DE PROCESOS Y SERVICIOS ===
Fecha: $fecha
========================================

=== TOP 5 PROCESOS POR CPU ===
"@

$procesosCPU = Get-Process | Sort-Object CPU -Descending | Select-Object -First 5
foreach ($proc in $procesosCPU) {
    $contenido += "$($proc.Name.PadRight(20)) CPU: $($proc.CPU.ToString('F2'))`n"
}

$contenido += "`n=== TOP 5 PROCESOS POR MEMORIA ===`n"
$procesosMem = Get-Process | Sort-Object WorkingSet -Descending | Select-Object -First 5
foreach ($proc in $procesosMem) {
    $memMB = [math]::Round($proc.WorkingSet / 1MB, 2)
    $contenido += "$($proc.Name.PadRight(20)) Memoria: ${memMB} MB`n"
}

$contenido += "`n=== SERVICIOS EJECUTÁNDOSE ===`n"
$servicios = Get-Service | Where-Object Status -eq "Running"
foreach ($serv in $servicios) {
    $contenido += "$($serv.Name.PadRight(30)) Estado: $($serv.Status)`n"
}

# Mostrar y guardar
Write-Host $contenido
$contenido | Out-File -FilePath $archivo -Encoding UTF8
Write-Host "`nReporte guardado en: $archivo"

Instrucciones de entrega:

  1. Guardar el script como gestion_procesos.ps1
  2. Ejecutar el script: powershell -ExecutionPolicy Bypass -File gestion_procesos.ps1
  3. Capturar la salida del script
  4. Entregar: script + captura de ejecución
