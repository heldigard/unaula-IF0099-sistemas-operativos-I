1. El Estándar de la Nube: Bash

Bash (Bourne Again SHell) es la interfaz por defecto en casi todas las distribuciones Linux.

Filosofía Linux: Todo es un archivo. Bash manipula texto para configurar el sistema. 
# Navegación y Archivos
ls -la          # Listar con detalles y ocultos
cd /etc         # Ir a configuración
pwd             # ¿Dónde estoy?
mkdir portal    # Crear carpeta
touch index.html # Crear archivo vacío

2. El Estándar Corporativo: PowerShell

PowerShell no solo procesa texto, procesa Objetos .NET. Es fundamental para administrar Windows Server y Azure.

Ventaja: Al devolver objetos, puedes acceder a propiedades (como el tamaño de un archivo) sin usar filtros de texto complejos como awk o sed. 
# Navegación y Archivos (PowerShell)
Get-ChildItem               # Equivalente a ls
Set-Location C:\Windows     # Equivalente a cd
Get-Location                # Equivalente a pwd
New-Item -Type Directory -Name "Web" # Crear carpeta
New-Item -Type File -Name "data.txt" # Crear archivo

4. Actividad Práctica Híbrida

Reto de Comandos Cruzados

Tarea Linux: En su VM Ubuntu, cree un script llamado init.sh que cree una carpeta /var/www/ucs, le asigne permisos 755 y cree un archivo index.html.

Tarea Windows: En su Windows host (o VM), abra PowerShell como Administrador y ejecute: Get-Service | Where-Object {$_.Status -eq "Running"} | Select-Object -First 5. Documente qué servicios encontró.
