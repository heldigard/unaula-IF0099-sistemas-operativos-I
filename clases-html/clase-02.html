Objetivos de Aprendizaje

Resultado de Aprendizaje: Identifica la estructura y los tipos de los sistemas operativos.

Glosario de la Sesión

  • CLI (Command Line Interface): Interfaz de Línea de Comandos, donde interactuamos mediante texto.

  • FS (File System): Sistema de Archivos, la forma en que el SO organiza los datos en el disco.
  • Shell: El intérprete de comandos que traduce nuestras órdenes al Kernel.

1. Estructura de Directorios de Linux

El Sistema de Archivos Jerárquico

Linux usa una estructura de árbol con un directorio raíz /. Todos los archivos y directorios cuelgan de este punto.

/ (raíz) ├── bin/ → Programas esenciales (ls, cp, cat) ├── boot/ → Archivos de arranque ├── dev/ → Dispositivos (sda, tty, null) ├── etc/ → Configuración del sistema ├── home/ → Directorios de usuarios │ └── usuario/ │ ├── documentos/ │ ├── descargas/ │ └── proyecto/ ├── lib/ → Librerías del sistema ├── opt/ → Software opcional ├── proc/ → Información del kernel (virtual) ├── root/ → Home del superusuario ├── sbin/ → Binarios del sistema ├── tmp/ → Archivos temporales ├── usr/ → Programas de usuario └── var/ → Datos variables (logs, spool)

Directorios Importantes para Conocer

Directorio Contenido Uso Común
/home Directorios personales de usuarios Tus archivos y proyectos
/etc Archivos de configuración passwd, fstab, ssh/
/var Datos variables /var/log para logs
/tmp Archivos temporales Se vacía al reiniciar

Path Absoluto vs Relativo

Tipo Descripción Ejemplo
Absoluto Desde la raíz / /home/usuario/documentos
Relativo Desde el directorio actual documentos o ../documentos
Ejemplo de paths: Si estás en: /home/usuario/ Path absoluto: /etc/passwd → Siempre funciona desde cualquier lugar Path relativo: documentos/ → Directorio en el lugar actual ../otro_usuario/ → Un nivel arriba ./script.sh → Directorio actual (./ es opcional)

Recordatorio

~ (tilde) es un atajo para tu directorio home. cd ~/documentos te lleva a /home/tu_usuario/documentos.

2. Navegación Básica (15 min)

Comandos Esenciales

Comando Descripción Ejemplo
pwd Print Working Directory - Mostrar directorio actual pwd
ls List - Listar archivos ls -la
cd Change Directory - Cambiar directorio cd /etc

Ejemplos Prácticos

# Mostrar directorio actual
estudiante@ubuntu-server:~$ pwd
/home/estudiante

# Listar archivos (simple)
estudiante@ubuntu-server:~$ ls
descargas  documentos  proyectos

# Listar con detalles (-l) y ocultos (-a)
estudiante@ubuntu-server:~$ ls -la
total 24
drwxr-xr-x 5 estudiante estudiante 4096 Feb 10 10:30 .
drwxr-xr-x 3 root       root       4096 Feb 10 09:00 ..
drwxr-xr-x 2 estudiante estudiante 4096 Feb 10 10:15 descargas
drwxr-xr-x 2 estudiante estudiante 4096 Feb 10 10:20 documentos
drwxr-xr-x 2 estudiante estudiante 4096 Feb 10 10:25 proyectos
-rw-r--r-- 1 estudiante estudiante  123 Feb 10 10:28 .bashrc

# Cambiar a /etc
estudiante@ubuntu-server:~$ cd /etc
estudiante@ubuntu-server:/etc$ pwd
/etc

# Volver al home (~)
estudiante@ubuntu-server:/etc$ cd ~
estudiante@ubuntu-server:~$ pwd
/home/estudiante

# Ir al directorio anterior (..)
estudiante@ubuntu-server:~/documentos$ cd ..
estudiante@ubuntu-server:~$ pwd
/home/estudiante

Atención con los archivos ocultos

En Linux, los archivos que empiezan con . (punto) son ocultos. Usa ls -a para verlos todos.

3. Manipulación de Archivos (15 min)

Comandos de Gestión

Comando Descripción Ejemplo
touch Crear archivo vacío o actualizar timestamp touch archivo.txt
mkdir Make Directory - Crear directorio mkdir dir_prueba
cp Copy - Copiar archivos cp origen.txt copia.txt
mv Move - Mover o renombrar mv viejo.txt nuevo.txt
rm Remove - Eliminar archivos rm archivo.txt
rm -r Remove recursive - Eliminar directorios rm -r directorio/

Ejemplos Prácticos

# Crear estructura de directorios
estudiante@ubuntu-server:~$ mkdir -p proyecto/{src,docs,tests}
estudiante@ubuntu-server:~$ ls proyecto/
docs  src  tests

# Crear archivos
estudiante@ubuntu-server:~$ touch proyecto/src/main.py
estudiante@ubuntu-server:~$ touch proyecto/src/utils.py
estudiante@ubuntu-server:~$ touch proyecto/docs/README.md

# Copiar archivo
estudiante@ubuntu-server:~$ cp proyecto/src/main.py proyecto/src/main.py.bak

# Mover/renombrar (mv hace ambas cosas)
estudiante@ubuntu-server:~$ mv proyecto/src/main.py.bak proyecto/src/main_backup.py

# Verificar
estudiante@ubuntu-server:~$ ls proyecto/src/
main.py  main_backup.py  utils.py

# Eliminar archivo
estudiante@ubuntu-server:~$ rm proyecto/src/main_backup.py

# Eliminar directorio completo
estudiante@ubuntu-server:~$ rm -r proyecto/tests/
estudiante@ubuntu-server:~$ ls proyecto/
docs  src

⚠️ CUIDADO: rm -rf

rm -rf elimina recursivamente y sin preguntar. Un error puede borrar archivos importantes. Siempre verifica el comando antes de presionar Enter.

4. Visualización de Archivos (10 min)

Comandos de Lectura

Comando Descripción Cuándo usarlo
cat Muestra todo el contenido Archivos pequeños
less Permite navegar (paginar) Archivos grandes
head Primeras líneas (defecto: 10) Ver inicio de archivo
tail Últimas líneas (defecto: 10) Ver final de archivo/logs
grep Busca un patrón en archivo Encontrar texto específico

Ejemplos Prácticos

# Ver contenido completo (cat)
estudiante@ubuntu-server:~$ cat /etc/hostname
ubuntu-server

# Ver archivo grande con paginación (less)
estudiante@ubuntu-server:~$ less /var/log/syslog
# Usa: q para salir, flechas para navegar, /patrón para buscar

# Ver primeras 5 líneas
estudiante@ubuntu-server:~$ head -n 5 /etc/passwd
root:x:0:0:root:/root:/bin/bash
daemon:x:1:1:daemon:/usr/sbin:/usr/sbin/nologin
bin:x:2:2:bin:/bin:/usr/sbin/nologin
sys:x:3:3:sys:/dev:/usr/sbin/nologin
sync:x:4:65534:sync:/bin:/bin/sync

# Ver últimas 5 líneas
estudiante@ubuntu-server:~$ tail -n 5 /etc/passwd

# Buscar texto específico
estudiante@ubuntu-server:~$ grep "root" /etc/passwd
root:x:0:0:root:/root:/bin/bash

# Combinaciones potentes
estudiante@ubuntu-server:~$ ps aux | grep "apache"
# Muestra procesos de apache

# Ver logs en tiempo real
estudiante@ubuntu-server:~$ tail -f /var/log/syslog
# Ctrl+C para salir

Tip Útil

grep es uno de los comandos más útiles. Combínalo con | (pipe) para filtrar salida de otros comandos.

🛠️ Ejercicio Práctico Guiado: Explorando el Sistema (8 min)

Alternativa: Si no tienes acceso a /var/log, practica con archivos en tu home usando Webminal.

Objetivo

Practicar la visualización de archivos usando diferentes comandos para diferentes propósitos.

Parte 1: Explorar Archivos del Sistema (4 min)

# 1. Ver el nombre de tu servidor
cat /etc/hostname

# 2. Ver información del sistema operativo
cat /etc/os-release | head -5

# 3. Buscar tu usuario en el archivo de contraseñas
grep "$USER" /etc/passwd

# 4. Ver los últimos 10 comandos ejecutados (requiere que hayas usado la terminal)
head -10 ~/.bash_history 2>/dev/null || echo "Aún no hay historial"

# 5. Contar cuántas líneas tiene un archivo del sistema
wc -l /etc/passwd

Parte 2: Explorar Logs (4 min)

# 1. Ver últimas entradas del syslog (necesita sudo)
sudo tail -n 20 /var/log/syslog

# 2. Buscar errores en el syslog
grep -i "error" /var/log/syslog | tail -5

# 3. Ver procesos en ejecución y filtrar por tu usuario
ps aux | grep "$USER" | head -10

# 4. Usar less para explorar un archivo grande (presiona 'q' para salir)
sudo less /var/log/syslog
# Dentro de less:
# - Usa / para buscar (ej: /error)
# - Usa n para siguiente coincidencia
# - Usa N para coincidencia anterior
# - Usa q para salir

✅ Desafío Extra

Intenta encontrar tu dirección IP en el archivo /etc/hosts usando grep:

grep "127\.0\|localhost" /etc/hosts

5. Permisos Básicos (15 min)

Sistema de Permisos Linux

Cada archivo en Linux tiene permisos para tres categorías:

  • Usuario (u) - El dueño del archivo
  • Grupo (g) - El grupo del archivo
  • Otros (o) - El resto de usuarios

Tipos de Permiso

Tipos de permiso: r (read) = 4 = Lectura w (write) = 2 = Escritura x (execute) = 1 = Ejecución Ejemplo: 755 7 = 4+2+1 = rwx (propietario: todo) 5 = 4+1 = r-x (grupo: leer y ejecutar) 5 = 4+1 = r-x (otros: leer y ejecutar) drwxr-xr-x archivo.txt d = directorio rwx = permisos propietario r-x = permisos grupo r-x = permisos otros

Comandos de Permisos

Comando Descripción Ejemplo
chmod Change Mode - Cambiar permisos chmod 755 script.sh
chmod +x Agregar permiso de ejecución chmod +x script.sh
chown Change Owner - Cambiar dueño chown user:grupo file
sudo SuperUser DO - Ejecutar como root sudo apt update

Ejemplos Prácticos

# Ver permisos actuales
estudiante@ubuntu-server:~$ ls -la script.sh
-rw-r--r-- 1 estudiante estudiante 123 Feb 10 10:30 script.sh
# No es ejecutable (no tiene 'x')

# Hacer ejecutable con +x
estudiante@ubuntu-server:~$ chmod +x script.sh
estudiante@ubuntu-server:~$ ls -la script.sh
-rwxr-xr-x 1 estudiante estudiante 123 Feb 10 10:30 script.sh
# Ahora es ejecutable

# Usar notación numérica
estudiante@ubuntu-server:~$ chmod 644 archivo.txt
# 6 = rw- (propietario)
# 4 = r-- (grupo)
# 4 = r-- (otros)

# Quitar permiso de escritura a otros
estudiante@ubuntu-server:~$ chmod o-w archivo.txt

# Cambiar propietario (requiere sudo)
estudiante@ubuntu-server:~$ sudo chown root:root archivo.txt
estudiante@ubuntu-server:~$ ls -la archivo.txt
-rw-r--r-- 1 root root 456 Feb 10 10:35 archivo.txt

Permisos Comunes

  • 644 = Archivos normales (rw-r--r--)
  • 755 = Scripts ejecutables (rwxr-xr-x)
  • 600 = Archivos privados (rw-------)

🛠️ Ejercicio Práctico Guiado: Jugando con Permisos (8 min)

Alternativa: Los permisos funcionan igual en Webminal. Para usar sudo, necesitas una VM propia o Oracle Cloud Free Tier.

Objetivo

Practicar la asignación de permisos en diferentes escenarios.

Parte 1: Crear un Script y Hacerlo Ejecutable

# Navega al directorio de la práctica
cd ~/practica_clase_02

# Crea un script simple con contenido
cat > proyecto_so/bin/hola_mundo.sh << 'EOF'
#!/bin/bash
echo "¡Hola, Sistemas Operativos!"
echo "Fecha actual: $(date)"
EOF

# Verificar que NO es ejecutable (no tiene 'x')
ls -l proyecto_so/bin/hola_mundo.sh

# Intentar ejecutarlo (debería fallar)
./proyecto_so/bin/hola_mundo.sh
# Error: Permission denied

# Hacerlo ejecutable
chmod +x proyecto_so/bin/hola_mundo.sh

# Verificar que AHORA sí es ejecutable (tiene 'x')
ls -l proyecto_so/bin/hola_mundo.sh

# Ejecutar el script
./proyecto_so/bin/hola_mundo.sh

Parte 2: Probar Diferentes Permisos

# Crear un archivo de configuración privado
touch proyecto_so/config.txt
echo "password=secreto123" > proyecto_so/config.txt

# Hacerlo privado (solo el propietario puede leer/escribir)
chmod 600 proyecto_so/config.txt

# Verificar permisos (-rw-------)
ls -l proyecto_so/config.txt

# Probar que otros no pueden leerlo
# (Esto simula que otros usuarios no pueden ver el archivo)

# Crear un archivo de solo lectura para todos
touch proyecto_so/publico.txt
echo "Información pública" > proyecto_so/publico.txt
chmod 444 proyecto_so/publico.txt

# Intentar modificarlo (debería fallar)
echo "Nuevo texto" >> proyecto_so/publico.txt

# Verificar los permisos
ls -l proyecto_so/*.txt

⚠️ Importante

Nunca guardes contraseñas reales en archivos de texto plano. Este es solo un ejercicio educativo.

6. Ejercicio Integrador (10 min)

Crear Estructura de Proyecto

Crea la siguiente estructura de directorios y archivos:

proyecto_so/ ├── documentos/ │ ├── notas.txt │ └── referencias.txt └── scripts/ ├── respaldo.sh └── monitoreo.sh

Solución Paso a Paso

# 1. Crear estructura de directorios
mkdir -p proyecto_so/{documentos,scripts}

# 2. Crear archivos vacíos
touch proyecto_so/documentos/notas.txt
touch proyecto_so/documentos/referencias.txt
touch proyecto_so/scripts/respaldo.sh
touch proyecto_so/scripts/monitoreo.sh

# 3. Verificar estructura
tree proyecto_so 2>/dev/null || find proyecto_so -type f

proyecto_so/
├── documentos/
│   ├── notas.txt
│   └── referencias.txt
└── scripts/
    ├── respaldo.sh
    └── monitoreo.sh

# 4. Hacer scripts ejecutables
chmod +x proyecto_so/scripts/*.sh

# 5. Verificar permisos
ls -la proyecto_so/scripts/
total 8
-rwxr-xr-x 1 estudiante estudiante 0 Feb 10 11:00 monitoreo.sh
-rwxr-xr-x 1 estudiante estudiante 0 Feb 10 11:00 respaldo.sh

Actividad: Script de Automatización

Tiempo: 20 minutos

Objetivo: Crear un script bash que automatice la creación de estructuras de directorios

Script Bash: crear_estructura.sh

#!/bin/bash
# Nombre: crear_estructura.sh
# Autor: [Tu Nombre]
# Fecha: 2026-02-10
# Descripción: Script para crear estructura de proyecto

echo "=== Creando Estructura de Proyecto ==="
echo ""

# Crear directorios principales
echo "1. Creando directorios..."
mkdir -p proyecto/{src,docs,tests,data,output}
echo "   ✓ Directorios creados"

# Crear archivos base
echo ""
echo "2. Creando archivos base..."
touch proyecto/src/main.py
touch proyecto/src/utils.py
touch proyecto/docs/README.md
touch proyecto/docs/NOTAS.md
touch proyecto/tests/test_main.py
echo "   ✓ Archivos creados"

# Escribir contenido en README
echo ""
echo "3. Escribiendo README.md..."
cat > proyecto/docs/README.md << 'EOF'
# Proyecto de Sistemas Operativos

## Estructura
- src/: Código fuente
- docs/: Documentación
- tests/: Pruebas unitarias
- data/: Datos de entrada
- output/: Resultados

## Autor
[Tu Nombre]
EOF
echo "   ✓ README.md creado"

# Establecer permisos
echo ""
echo "4. Estableciendo permisos..."
chmod +x proyecto/src/main.py
chmod +x proyecto/tests/test_main.py
echo "   ✓ Permisos establecidos"

# Mostrar estructura final
echo ""
echo "=== Estructura Creada ==="
tree proyecto 2>/dev/null || find proyecto | sed 's|[^/]*/| |g'

# Mostrar espacio usado
echo ""
echo "Espacio en disco usado:"
du -sh proyecto

echo ""
echo "¡Proyecto creado exitosamente!"

Para Usar el Script

# 1. Crear el archivo del script
nano crear_estructura.sh
# Pegar el contenido anterior
# Ctrl+O para guardar, Ctrl+X para salir

# 2. Hacer el script ejecutable
chmod +x crear_estructura.sh

# 3. Ejecutar el script
./crear_estructura.sh

# 4. Verificar resultado
ls -la proyecto/

Tip

Si usas mkdir -p, no obtendrás error si el directorio ya existe. El flag -p crea directorios padre si es necesario.
