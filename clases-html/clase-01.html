1. ¿Qué es un Sistema Operativo?

Es el software maestro que gestiona el hardware y actúa como intermediario entre el usuario y la máquina. Un SO profesional tiene dos responsabilidades fundamentales:

Gestor de Recursos (System View)

Es el "gerente" del computador. Decide qué proceso usa la CPU, cuánta RAM recibe una app y quién puede escribir en el disco. Su meta es la Eficiencia.

Máquina Extendida (User View)

Es una "capa de confort". Oculta la complejidad física (voltajes, sectores, interrupciones) tras una interfaz limpia (GUI/CLI). Su meta es la Abstracción.

2. Ubicación en la Arquitectura Computacional

El SO no es un programa cualquiera; es el cimiento sobre el que corre todo lo demás.

Privilegio de Ejecución

El SO corre en el nivel de privilegio más alto del procesador (Ring 0). Si una aplicación intentara tocar el hardware directamente sin pedir permiso al SO, el procesador generaría una excepción y mataría la aplicación para proteger el equipo.

3. El Corazón del Sistema: El Kernel

El Kernel (Núcleo) es la parte del SO que reside permanentemente en la memoria RAM principal.

Tipo de KernelCaracterísticasEjemplo Real
Monolítico Todos los servicios (Red, FS, Drivers) corren en el espacio del kernel. Muy rápido pero menos tolerante a fallos. Linux, FreeBSD
Microkernel Solo lo esencial en el kernel. Los drivers corren como procesos de usuario. Muy estable pero más lento. QNX (Usado en autos y aviones)
Híbrido Estructura modular cargando servicios críticos en Ring 0 para ganar velocidad. Windows NT (Kernel de Win 10/11)

5. Ejemplos Prácticos: Linux vs Windows

Compara cómo se hacen las mismas tareas en ambos sistemas. Esto te ayudará a entender las diferencias prácticas.

📊 Ejemplo 1: Ver información del sistema

Linux (Ubuntu)
# Ver información del sistema
uname -a
# Salida: Linux ubuntu-server 5.15.0...

# Ver versión de Ubuntu
lsb_release -a
# Salida: Ubuntu 22.04.3 LTS

# Ver arquitectura
dpkg --print-architecture
# Salida: amd64
Windows (PowerShell)
# Ver información del sistema
systeminfo | findstr /B /C:"OS Name" /C:"OS Version"
# Salida: OS Name: Microsoft Windows 11 Pro

# Ver versión de Windows
Get-ComputerInfo | Select OsName, OsVersion
# Salida: Microsoft Windows 11 Pro | 10.0.22621

# Ver arquitectura
(Get-WmiObject -Class Win32_Processor).Architecture
# Salida: 9 (x64)

💾 Ejemplo 2: Ver uso de disco

Linux
# Ver espacio en disco
df -h
# Muestra: Filesystem Size Used Avail Use%
#          /dev/sda1  20G  8G   11G  42%

# Ver tamaño de carpetas
du -sh /var/log
# Salida: 2.1G /var/log
Windows
# Ver espacio en disco
Get-Volume | Select DriveLetter, Size, SizeRemaining
# Muestra: C | 256GB | 180GB

# Ver tamaño de carpetas
(Get-ChildItem C:\Windows -Recurse | 
    Measure-Object -Property Length -Sum).Sum / 1GB
# Salida: 15.23 GB

⚡ Ejemplo 3: Ver procesos activos

Linux
# Ver procesos (simplificado)
ps aux | head -5
# Muestra: USER PID %CPU %MEM COMMAND

# Ver en tiempo real
top
# Interfaz interactiva
Windows
# Ver procesos
Get-Process | Select-Object -First 5
# Muestra: Name, Id, CPU, WorkingSet

# Ver en tiempo real
Get-Process | Sort-Object CPU -Descending | 
    Select-Object -First 10

6. Comandos Profesionales de Auditoría de Hardware

Un ingeniero debe conocer el silicio que gestiona antes de instalar cualquier software. Aquí tienes la cheat sheet completa para auditoría en ambos sistemas.

🔍 Inspección Completa en Linux (Bash)

# ═══════════════════════════════════════
# INFORMACIÓN GENERAL DEL SISTEMA
# ═══════════════════════════════════════
uname -a                    # Kernel + hostname
hostnamectl                 # Info detallada del host
cat /etc/os-release         # Versión de distribución
uptime                      # Tiempo encendido

# ═══════════════════════════════════════
# INFORMACIÓN DE HARDWARE
# ═══════════════════════════════════════
lscpu                       # CPU: cores, threads, cache
free -h                     # RAM: total, usada, libre
lsblk                       # Discos y particiones
df -h                       # Espacio en disco usado
lspci                       # Dispositivos PCI (GPU, etc.)
lsusb                       # Dispositivos USB

# ═══════════════════════════════════════
# INFORMACIÓN DE RED
# ═══════════════════════════════════════
ip addr                     # Interfaces de red
ip route                    # Tabla de enrutamiento
ss -tuln                    # Puertos en escucha

🔍 Inspección Completa en Windows (PowerShell)

# ═══════════════════════════════════════
# INFORMACIÓN GENERAL DEL SISTEMA
# ═══════════════════════════════════════
systeminfo                  # Reporte completo
Get-ComputerInfo            # Info del sistema
Get-Date                    # Fecha y hora actual

# ═══════════════════════════════════════
# INFORMACIÓN DE HARDWARE
# ═══════════════════════════════════════
Get-CimInstance Win32_Processor
# CPU: cores, threads, velocidad

Get-CimInstance Win32_PhysicalMemory | 
    Measure-Object Capacity -Sum
# RAM total en bytes

Get-PhysicalDisk            # Discos físicos
Get-Volume                  # Volúmenes y espacio
Get-CimInstance Win32_VideoController
# Info de GPU

# ═══════════════════════════════════════
# INFORMACIÓN DE RED
# ═══════════════════════════════════════
Get-NetIPAddress            # Interfaces de red
Get-NetRoute                # Tabla de enrutamiento
Get-NetTCPConnection        # Conexiones TCP activas

💡 Tip: En Windows, también puedes usar msinfo32 para una interfaz gráfica completa de información del sistema.

El Rol del Administrador de Sistemas en el Mundo Real

Entender qué es un SO no es solo teoría: es la base de tu carrera profesional.

¿Qué hace un Administrador de Sistemas?

Un SysAdmin (Administrador de Sistemas) es el profesional responsable de que los servidores funcionen 24/7. Sus responsabilidades incluyen:

  • Infraestructura: Instalar, configurar y mantener servidores (físicos y virtuales)
  • Seguridad: Aplicar parches, configurar firewalls, gestionar usuarios y permisos
  • Monitoreo: Vigilar rendimiento, capacidad y disponibilidad
  • Respaldo: Implementar y probar estrategias de recovery
  • Documentación: Mantener procedimientos actualizados para todo

🛠️ Práctica Laboral

📊 Caso de Estudio: ¿Por qué Netflix usa Linux?

Contexto: Netflix procesa más de 450 millones de horas de video semanalmente a través de su plataforma de streaming.

Decisión de Arquitectura: Netflix migró de sistemas propietarios a Linux en servidores bare-metal con arquitectura de microservicios.

Factores decisivos:

  • Costo: Eliminar licencias de Windows Server ahorra millones anuales
  • Personalización: Kernel tuneado específicamente para throughput de video
  • Escalabilidad: FreeBSD + NGINX para CDN (Open Connect)
  • Comunidad: Acceso a herramientas open-source de monitoreo

Pregunta de análisis: ¿Por qué crees que Netflix NO usa Windows Server para sus servidores de streaming, a pesar de tener los recursos para pagar las licencias?
