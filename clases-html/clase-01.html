1. ¿Qué es un Sistema Operativo?

Es el software maestro que gestiona el hardware y actúa como intermediario entre el usuario y la máquina. Un SO profesional tiene dos responsabilidades fundamentales:

Gestor de Recursos (System View)

Es el "gerente" del computador. Decide qué proceso usa la CPU, cuánta RAM recibe una app y quién puede escribir en el disco. Su meta es la Eficiencia.

Máquina Extendida (User View)

Es una "capa de confort". Oculta la complejidad física (voltajes, sectores, interrupciones) tras una interfaz limpia (GUI/CLI). Su meta es la Abstracción.

2. Ubicación en la Arquitectura Computacional

El SO no es un programa cualquiera; es el cimiento sobre el que corre todo lo demás.

Privilegio de Ejecución

El SO corre en el nivel de privilegio más alto del procesador (Ring 0). Si una aplicación intentara tocar el hardware directamente sin pedir permiso al SO, el procesador generaría una excepción y mataría la aplicación para proteger el equipo.

3. El Corazón del Sistema: El Kernel

El Kernel (Núcleo) es la parte del SO que reside permanentemente en la memoria RAM principal.

Tipo de KernelCaracterísticasEjemplo Real
Monolítico Todos los servicios (Red, FS, Drivers) corren en el espacio del kernel. Muy rápido pero menos tolerante a fallos. Linux, FreeBSD
Microkernel Solo lo esencial en el kernel. Los drivers corren como procesos de usuario. Muy estable pero más lento. QNX (Usado en autos y aviones)
Híbrido Estructura modular cargando servicios críticos en Ring 0 para ganar velocidad. Windows NT (Kernel de Win 10/11)

5. Comandos Profesionales de Auditoría de Hardware

Un ingeniero debe conocer el silicio que gestiona antes de instalar cualquier software.

Inspección en Linux (Bash)

# Datos del Kernel y Hostname
uname -a

# Ver detalles de la CPU (Cores, Cache)
lscpu

# Ver memoria RAM física y usada
free -h

# Listar discos y particiones
lsblk

Inspección en Windows (PowerShell)

# Reporte técnico completo
systeminfo

# Ver BIOS y Manufacturador
Get-CimInstance Win32_BIOS

# Ver procesadores lógicos
Get-CimInstance Win32_Processor | Select-Object Name, NumberOfCores

# Info de placa base
wmic baseboard get product

El Rol del Administrador de Sistemas en el Mundo Real

Entender qué es un SO no es solo teoría: es la base de tu carrera profesional.

¿Qué hace un Administrador de Sistemas?

Un SysAdmin (Administrador de Sistemas) es el profesional responsable de que los servidores funcionen 24/7. Sus responsabilidades incluyen:

  • Infraestructura: Instalar, configurar y mantener servidores (físicos y virtuales)
  • Seguridad: Aplicar parches, configurar firewalls, gestionar usuarios y permisos
  • Monitoreo: Vigilar rendimiento, capacidad y disponibilidad
  • Respaldo: Implementar y probar estrategias de recovery
  • Documentación: Mantener procedimientos actualizados para todo
