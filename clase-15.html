Teoría: FTP y Protocolos de Transferencia

¿Qué es FTP?

FTP (File Transfer Protocol) es un protocolo de red estándar para transferir archivos entre un cliente y un servidor a través de una red TCP.

Características de FTP

  • Protocolo de capa de aplicación
  • Arquitectura cliente-servidor
  • Usa 2 puertos: 20 (datos) y 21 (control)
  • Autenticación con usuario/contraseña
  • Soporta transferencia binaria y ASCII
  • Permite listar, subir, bajar archivos

Modos de Conexión

Modo Activo:

  • Cliente abre puerto aleatorio
  • Servidor se conecta desde puerto 20
  • Problemas con firewalls/NAT

Modo Pasivo:

  • Servidor abre puerto aleatorio
  • Cliente se conecta a ese puerto
  • Más compatible con firewalls

FTP vs FTPS vs SFTP

ProtocoloCifradoPuertoDescripción
FTPNo20/21Protocolo original, texto plano
FTPSSSL/TLS990/989FTP sobre SSL/TLS (implícito)
FTPESSSL/TLS20/21FTP con TLS explícito
SFTPSSH22FTP sobre SSH (diferente protocolo)
Advertencia de Seguridad:

FTP tradicional transmite credenciales y datos en texto plano. Para producción, usar SFTP o FTPS.

Instalación de vsftpd

Requisitos previos:
  • VM con Ubuntu Server 22.04/24.04
  • Usuario con privilegios sudo
  • Conexión a Internet

Paso 1: Actualizar e instalar

# Actualizar sistema
sudo apt update
sudo apt upgrade -y

# Instalar vsftpd
sudo apt install vsftpd -y

# Verificar instalación
vsftpd -version

Paso 2: Verificar el servicio

# Verificar estado
sudo systemctl status vsftpd

# Habilitar inicio automático
sudo systemctl enable vsftpd

# Verificar puertos en escucha
sudo ss -tlnp | grep vsftpd
Ubicación de archivos:
  • /etc/vsftpd.conf - Configuración principal
  • /etc/vsftpd.userlist - Lista de usuarios permitidos
  • /home/usuario/ftp - Directorio FTP por defecto
  • /var/log/vsftpd.log - Logs

Configuración Básica

Paso 1: Configurar vsftpd

# Hacer backup del archivo original
sudo cp /etc/vsftpd.conf /etc/vsftpd.conf.backup

# Editar configuración
sudo nano /etc/vsftpd.conf

Configuración recomendada:

# Habilitar y configurar
anonymous_enable=NO
local_enable=YES
write_enable=YES
dirmessage_enable=YES
xferlog_enable=YES
connect_from_port_20=YES
xferlog_std_format=YES
listen=NO
listen_ipv6=YES
pam_service_name=vsftpd
userlist_enable=YES
tcp_wrappers=YES

# Configurar directorio chroot
chroot_local_user=YES
allow_writeable_chroot=YES

# Configurar modo pasivo
pasv_enable=YES
pasv_min_port=10000
pasv_max_port=10100

# Limitar usuarios
userlist_file=/etc/vsftpd.userlist
userlist_deny=NO

Paso 2: Configurar firewall

# Permitir puerto 21 (control)
sudo ufw allow 21/tcp

# Permitir rango pasivo
sudo ufw allow 10000:10100/tcp

# Verificar firewall
sudo ufw status

Paso 3: Reiniciar servicio

# Reiniciar vsftpd
sudo systemctl restart vsftpd

# Verificar estado
sudo systemctl status vsftpd

Configurar Usuario FTP

Paso 1: Crear usuario FTP

# Crear usuario
sudo adduser ftpuser

# (Responder prompts para contraseña y datos)

Paso 2: Crear directorio FTP

# Crear directorio con permisos
sudo mkdir -p /home/ftpuser/ftp/files
sudo chown nobody:nogroup /home/ftpuser/ftp
sudo chmod a-w /home/ftpuser/ftp
sudo chown -R ftpuser:ftpuser /home/ftpuser/ftp/files

# Crear archivo de prueba
echo "Archivo de prueba FTP" | sudo tee /home/ftpuser/ftp/files/prueba.txt

Paso 3: Agregar usuario a lista permitida

# Agregar usuario a lista
echo "ftpuser" | sudo tee -a /etc/vsftpd.userlist

# Verificar lista
cat /etc/vsftpd.userlist

Paso 4: Reiniciar servicio

sudo systemctl restart vsftpd

Probar Transferencia

Opción 1: Probar con cliente FTP (desde otra VM o host)

# Conectarse al servidor
ftp IP_DEL_SERVIDOR

# Usuario: ftpuser
# Contraseña: [la que configuraste]

# Comandos FTP básicos:
pwd                     # Ver directorio actual
ls                      # Listar archivos
get prueba.txt          # Descargar archivo
put archivo.txt         # Subir archivo
bye                     # Salir

Opción 2: Probar con cliente SFTP (más seguro)

# Conectarse con SFTP
sftp ftpuser@IP_DEL_SERVIDOR

# Comandos SFTP:
lpwd                    # Directorio local
pwd                     # Directorio remoto
ls                      # Listar remoto
lls                     # Listar local
get prueba.txt          # Descargar
put archivo.txt         # Subir
bye                     # Salir

Opción 3: Probar desde Windows (FileZilla o WinSCP)

Con FileZilla:

  1. Abrir FileZilla
  2. Host: IP_DEL_SERVIDOR
  3. Usuario: ftpuser
  4. Contraseña: [la que configuraste]
  5. Puerto: 21
  6. Hacer clic en "Quickconnect"

Verificar transferencia

# En el servidor, verificar archivos
ls -la /home/ftpuser/ftp/files/

# Ver logs de transferencia
sudo tail -f /var/log/vsftpd.log
Comandos FTP útiles:
  • bin - Modo binario (para archivos que no son texto)
  • ascii - Modo ASCII (para archivos de texto)
  • mget * - Descargar múltiples archivos
  • mput *.txt - Subir múltiples archivos
  • mdelete *.tmp - Borrar múltiples archivos
