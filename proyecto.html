📘 Guía del Proyecto

Administración de Servidores Linux/Windows

Proyecto Integrador - 5 Fases
← Acta de Concertación Evaluaciones Rúbricas

🎯 Objetivo del Proyecto

Propósito

Diseñar, implementar y asegurar una infraestructura de servidores híbrida (Linux + Windows) para una empresa ficticia, aplicando todos los conceptos del curso de forma incremental.

Producto Final

Al finalizar el curso, tendrás un portafolio profesional con:

  • Servidores Linux y Windows configurados y funcionando
  • Servicios web desplegados (Apache + IIS)
  • Sistema de monitoreo en funcionamiento
  • Documentación técnica completa
  • Scripts de automatización funcionales

🗓️ Fases del Proyecto

FASE 1: Fundamentos y Arquitectura (E1 - 15%)

Fecha: 25 Febrero
Tipo: Taller
Eval: E1

Objetivo: Definir la arquitectura tecnológica de la empresa.

Entregables:
  • Análisis de necesidades de la empresa ficticia
  • Comparativa de arquitecturas SO (monolítico vs microkernel)
  • Selección de Ubuntu Server + Windows Server
  • Diagrama de arquitectura de red
  • Lista de servicios y requisitos

Fase 2: Gestión de Procesos y Servicios (E2 - 15%)

Fecha: 11 Marzo
Tipo: Informe
Eval: E2

Objetivo: Implementar procesos críticos y servicios base.

Entregables:
  • Scripts de monitoreo (Bash + PowerShell)
  • Configuración de servicios esenciales
  • Gestión de prioridades y políticas
  • Matriz de procesos y servicios
  • Video demostración (5-7 min)

Fase 3: Evaluación Intermedia (E3 - 20%)

Fecha: 25 Marzo
Tipo: Examen Parcial
Eval: E3

Objetivo: Evaluar comprensión teórica antes de Semana Santa.

Evaluación:
  • Análisis de escenarios prácticos
  • Problemas de planificación de CPU
  • Comandos reales Linux/Windows
  • Sin memorización - enfoque en análisis

Fase 4: Seguridad y Hardening (E4 - 15%)

Fecha: 22 Abril
Tipo: Reporte
Eval: E4

Objetivo: Proteger la infraestructura implementada.

Entregables:
  • Matriz de riesgos (8+ identificados)
  • Scripts de hardening automatizado
  • Configuración de firewall básico
  • Auditoría de seguridad
  • Recomendaciones de mitigación

Fase 5: Proyecto Integrador (E5 - 15%) 🚀

Fecha: 6 Mayo
Tipo: Proyecto
Eval: E5

Objetivo: Integrar todo: servidores web + monitoreo.

Entregables:
  • Servidores web funcionando: Apache (Linux) + IIS (Windows)
  • Scripts integrales: Monitor de sistema completo
  • Sistema de monitoreo: CPU, memoria, disco, red, servicios
  • Documentación: Integración de Fases 1-4
  • Video: Demostración del sistema (8-12 min)

Fase 6: Entrega Final (E6 - 20%) 🎓

Fecha: 27 Mayo
Tipo: Proyecto Final
Eval: E6

Objetivo: Presentar el proyecto completo funcionando.

Entregables:
  • Sistema funcionando: Demostración en vivo (20-30 min)
  • Documentación técnica: Manual completo del sistema
  • Presentación: 15-20 diapositivas
  • Portafolio: Evidencias de todo el proceso
  • Sustentación: Defensa del proyecto + preguntas

📊 Evolución del Proyecto

Flujo de Trabajo

  1. Fase 1 (E1): Diseñas la arquitectura → Entregas: Diagrama + justificación
  2. Fase 2 (E2): Implementas servicios → Entregas: Scripts + video
  3. Fase 3 (E3): Evaluación de conocimientos → Examen parcial
  4. Fase 4 (E4): Aseguras el sistema → Entregas: Hardening + auditoría
  5. Fase 5 (E5): Integras servicios web → Entregas: Proyecto integrado funcionando
  6. Fase 6 (E6): Presentas todo → Sustentación final en vivo

Conexión entre Fases

Cada fase construye sobre la anterior:

  • Fase 2 implementa lo diseñado en Fase 1
  • Fase 3 valida conocimientos antes de continuar
  • Fase 4 protege lo construido en Fases 1-2
  • Fase 5 integra TODO en un sistema funcional
  • Fase 6 muestra el producto final profesional
