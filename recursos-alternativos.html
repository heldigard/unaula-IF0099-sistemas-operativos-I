Plan B: Recursos Alternativos Gratuitos

IF0099 - Sistemas Operativos I | Universidad Autónoma Latinoamericana

Alternativas para practicar cuando no tengas acceso al laboratorio Docker

¿Qué es el Plan B?

Si no puedes conectarte al laboratorio Docker del curso (por problemas de red, firewall, o conectividad), puedes usar cualquiera de estos recursos gratuitos para completar los ejercicios de la clase.

Todos los recursos verificados

Esta lista fue actualizada en Febrero 2026. Todos los recursos han sido verificados y están funcionando correctamente.

Terminales Linux en el Navegador

Recomendado Webminal

https://www.webminal.org

Tipo: Terminal Linux real en el navegador

Requisito: Registro gratuito (email)

Ideal para: Todos los ejercicios del curso

  • Sistema Linux completo con Ubuntu/Debian
  • Puedes guardar archivos entre sesiones
  • Soporta la mayoría de comandos del curso
  • Sin necesidad de instalar nada

Sin Registro JSLinux

https://bellard.org/jslinux/

Tipo: Emulador Linux completo

Requisito: Ninguno

Ideal para: Práctica rápida sin registro

  • Arranca en segundos
  • Varios sistemas: Alpine, Fedora, Windows
  • Perfecto para comandos básicos
  • Los cambios no se guardan

Tutorial Linux Survival

https://linuxsurvival.com

Tipo: Tutorial interactivo con terminal simulada

Requisito: Ninguno

Ideal para: Aprender comandos básicos guiados

  • Ejercicios paso a paso
  • Explicaciones en cada comando
  • Terminal simulada integrada
  • Disponible en español

Sin Registro PracticeLinux

https://www.practicelinux.com

Tipo: Terminal Linux en navegador

Requisito: Ninguno

Ideal para: Ejercicios rápidos

  • Sin registro requerido
  • Interfaz simple
  • Comandos básicos disponibles

Máquinas Virtuales Gratuitas (Con Root)

Para ejercicios que requieren permisos de administrador (sudo, systemctl, etc.):

VM Completa Oracle Cloud Free Tier

https://www.oracle.com/cloud/free/

Tipo: VM en la nube con acceso root completo

Requisito: Tarjeta de crédito para verificación (no se cobra)

  • Hasta 4 VMs ARM con 24GB RAM total
  • Acceso SSH completo con root
  • Sistema operativo a elegir (Ubuntu, Oracle Linux)
  • Ideal para systemctl, docker, htop

Nota: La tarjeta es solo para verificación de identidad. No se realizan cargos si usas solo el Free Tier.

Estudiantes Azure for Students

https://azure.microsoft.com/free/students/

Tipo: Crédito de $100 para servicios Azure

Requisito: Email institucional (.edu) - Sin tarjeta de crédito

  • $100 de crédito inicial
  • Crear VMs Linux con acceso root
  • Servicios gratuitos por 12 meses
  • Perfecto si tienes email @unaula.edu.co

Estudiantes FreeVPS.edu.pl

https://freevps.edu.pl

Tipo: VPS gratuito para estudiantes

Requisito: Email .edu y participación en el foro

  • 4GB RAM, 4 vCPU
  • 50GB de almacenamiento
  • Acceso root completo
  • Requiere posts en el foro mensualmente

Docker Play with Docker

https://labs.play-with-docker.com/

Tipo: Sesiones de Alpine Linux con Docker

Requisito: Cuenta de Docker Hub (gratuita)

  • Sesiones de 4 horas
  • Acceso root temporal
  • Perfecto para practicar Docker
  • Terminal completa en navegador

¿Qué Recurso Usar Según el Ejercicio?

Tipo de Ejercicio Recurso Recomendado Comandos Disponibles
Comandos básicos (ls, cd, mkdir, cp, mv) Webminal, JSLinux ls, cd, mkdir, cp, mv, rm, touch
Permisos (chmod, chown) Webminal, Oracle Cloud chmod, chown (limitado sin root)
Procesos (ps, top, kill) Webminal, Oracle Cloud ps, top, kill, htop (requiere VM)
Memoria (free, vmstat) Webminal, Oracle Cloud free, vmstat, cat /proc/meminfo
Servicios (systemctl) Oracle Cloud, Azure systemctl (requiere root)
Red (netstat, ss, ifconfig) Oracle Cloud, Play with Docker ss, ip, netstat (limitado)
Scripts bash Webminal, JSLinux Scripts completos con nano, vim

Guía Rápida de Inicio

Opción 1: Webminal (Más fácil)

1. Ve a https://www.webminal.org
2. Haz clic en "Register" (o usa tu cuenta existente)
3. Completa el registro con tu email
4. Haz clic en "Start Terminal"
5. ¡Listo! Tienes una terminal Linux completa

Opción 2: JSLinux (Sin registro)

1. Ve a https://bellard.org/jslinux/
2. Selecciona "Alpine Linux" o "Fedora"
3. Haz clic en "Boot"
4. Espera 5-10 segundos a que cargue
5. ¡Listo! La terminal está lista para usar

Opción 3: Oracle Cloud Free Tier (Para root)

1. Ve a https://www.oracle.com/cloud/free/
2. Crea una cuenta (requiere verificación con tarjeta)
3. En el dashboard, crea una VM "Always Free"
4. Elige Ubuntu 22.04 o similar
5. Descarga la clave SSH y conéctate:
   ssh -i key.pem ubuntu@
6. Usa sudo para comandos de administrador

Limitaciones a Considerar

Importante

Algunos recursos tienen limitaciones. Ten en cuenta:

  • Webminal: Sin acceso root, sesiones limitadas, algunos comandos restringidos
  • JSLinux: Los cambios se pierden al cerrar, sin persistencia
  • Oracle Cloud: Requiere tarjeta para verificación, límite de recursos
  • Play with Docker: Sesiones de solo 4 horas

Recomendación

Para la mayoría de ejercicios del curso, Webminal es suficiente. Para ejercicios que requieran systemctl, docker, o sudo, considera Oracle Cloud Free Tier o Azure for Students.
