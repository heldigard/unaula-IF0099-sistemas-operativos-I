1. ¿Qué es un Sistema Operativo?

Definición Simple

Un Sistema Operativo (SO) es el software que gestiona el hardware de tu computadora y provee servicios para los programas. Sin él, tu computadora sería un conjunto de componentes inútiles.

Glosario de Abreviaciones

  • SO: Sistema Operativo.
  • RAM (Random Access Memory): Memoria de acceso aleatorio, donde se guardan los datos que se están usando en el momento.
  • CPU (Central Processing Unit): Unidad Central de Procesamiento, el "cerebro" que ejecuta las instrucciones.
  • I/O o E/S (Entrada/Salida): Comunicación entre el SO y el hardware externo (teclado, disco, red).
  • VM (Virtual Machine): Máquina Virtual, un software que simula una computadora real dentro de otra.
  • CLI (Command Line Interface): Interfaz de Línea de Comandos, interacción con el SO mediante comandos de texto.
  • GUI (Graphical User Interface): Interfaz Gráfica de Usuario, interacción con el SO mediante ventanas y menús visuales.
  • API (Application Programming Interface): Interfaz de Programación de Aplicaciones, conjunto de funciones que permiten a programas interactuar con el SO.

Definición Clave

Sistema Operativo = Software que gestiona hardware + provee servicios a programas

¿Por qué es necesario?

Imagina que tu computadora es una fábrica:

  • Hardware = Máquinas, edificios, herramientas
  • Programas = Trabajadores que producen cosas
  • Sistema Operativo = El gerente que organiza todo

Sin el gerente (SO), los trabajadores (programas) pelearían por las máquinas (hardware), causando caos y colapsos.

2. Funciones Principales del Sistema Operativo

El SO realiza cuatro funciones fundamentales:

Función Descripción Ejemplo
Gestión de Procesos Administra qué programas se ejecutan y cuándo Permite que Chrome, Word y Spotify corran al mismo tiempo
Gestión de Memoria Controla el uso de la RAM Asigna memoria a programas y la libera cuando terminan
Gestión de Archivos Organiza cómo se guardan y recuperan los datos Carpetas, archivos, permisos de lectura/escritura
Gestión de Entrada/Salida Controla dispositivos como teclado, mouse, disco Lee lo que escribes, guarda archivos, muestra en pantalla

Analogía Simple

Procesos = Clientes en un restaurante | Memoria = Mesas disponibles | Archivos = Pedidos en cocina | E/S = Camareros tomando pedidos

3. Tipos de Arquitectura de Sistema Operativo

Los SO se organizan internamente de diferentes maneras. Entender estas arquitecturas es fundamental para comprender cómo funciona cada sistema operativo.

3.1 Tipos de Arquitectura

Los sistemas operativos se organizan internamente de diferentes maneras:

Tipo Características Ventajas Ejemplos
Monolítico Todo el SO en un solo bloque en el kernel. Servicios corren en modo kernel. Rápido, eficiente, menos overhead Linux, MS-DOS
Microkernel Solo lo mínimo en kernel. Servicios corren en espacio de usuario. Más estable, seguro, modular MINIX, QNX
Híbrido Combina ambos enfoques según necesidades. Balance entre rendimiento y estabilidad Windows, macOS

📚 Profundización

Estas arquitecturas se estudiarán en detalle en la Clase 04: Estructura del Sistema Operativo, donde analizaremos Kernel, Shell, System Calls y Modos de Operación.

🎯 ¿Qué usaremos en el curso?

Ubuntu Server (Linux) que tiene arquitectura monolítica. Es rápido, eficiente y el estándar en servidores modernos.

# 2. Configurar
CPU: 2 núcleos
Red: Adaptador Puente
ISO: Montar ISO de Ubuntu Server

# 3. Instalar Ubuntu Server
Usuario: estudiante
Hostname: ubuntu-server-so01

4.3 Primeros Comandos

Una vez instalado, practica estos comandos básicos:

Comandos Esenciales
# Actualizar el sistema
sudo apt update && sudo apt upgrade -y

# Ver información del sistema
uname -a
lsb_release -a

# Ver recursos
free -h
df -h

# Crear snapshot en VirtualBox (IMPORTANTE)
# VM → Snapshots → Take Snapshot → "Instalación Limpia"

Actividad 01: Instalación de Ubuntu Server en VirtualBox

Tipo: Práctica obligatoria

Entregable: Evidencias de instalación + VM funcionando

Objetivo

Instalar VirtualBox y crear una máquina virtual con Ubuntu Server 22.04 LTS completamente funcional.

Requisitos

  • VirtualBox instalado en tu computadora
  • ISO de Ubuntu Server 22.04 LTS descargado

  1. Sigue los pasos de la sección 4.3 para crear tu máquina virtual

Entregables

Entregable Descripción

VM funcionando Video o capturas mostrando que la VM inicia correctamente y puedes ejecutar comandos

Criterio Excelente (100%) Bueno (75%) Suficiente (50%) Insuficiente (0%)
