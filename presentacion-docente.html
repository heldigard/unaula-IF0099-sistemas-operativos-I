Sobre el Curso

Descripción

IF0099 - Sistemas Operativos I es un curso de 3 créditos del 4° semestre que proporciona los fundamentos teóricos y prácticos de los sistemas operativos modernos.

Objetivo principal: Comprender cómo funcionan los componentes internos de un SO (procesos, memoria, archivos, E/S) y desarrollar habilidades para administrar sistemas Linux.
student@linux:~$ whoami
future_systems_programmer
student@linux:~$ cat ~/goals.txt
- Master Linux terminal & Bash
- Manage Windows Server & PowerShell
- Configure Web Servers (Apache/IIS)
- Implement Security & Hardening
student@linux:~$ _

¿Qué aprenderás?

Unidad 1: Introducción a Sistemas Operativos

Arquitectura de SO, servicios, llamadas al sistema, evolución histórica.

Unidad 2: Gestión de Procesos

Procesos vs threads, PCB, estados, operaciones, comunicación IPC.

Unidad 3: Planificación de CPU

Algoritmos de planificación, criterios, tiempo real, multiprocesadores.

Unidad 4: Sincronización y Deadlocks

Sección crítica, semáforos, monitores, problemas clásicos, detección de deadlocks.

Unidad 5: Gestión de Memoria

Paginación, segmentación, memoria virtual, swapping, algoritmos de reemplazo.

Unidad 6: Sistemas de Archivos

Estructura de archivos, directorios, montaje, implementación (FAT, NTFS, ext4).

Unidad 7: Gestión de E/S

Hardware de E/S, polling, interrupciones, DMA, planificación de disco.

Unidad 8: Protección y Seguridad

Dominios de protección, capabilities, seguridad en sistemas distribuidos.

Enfoque del Curso

Plan Práctico v2.0: Sin programación en C

Este curso ha sido rediseñado para enfocarse 100% en la administración y configuración de sistemas operativos modernos. Aprenderás las habilidades que realmente se usan en el mundo laboral (SysAdmin, DevOps, Cloud).

🐧 Gestión de Linux

  • Dominio de la terminal y comandos Bash
  • Gestión de usuarios, grupos y permisos granulares (ACLs)

🪟 Gestión de Windows Server

  • Administración mediante PowerShell

  • Introducción a Active Directory

☁️ Cloud & Virtualización

  • Virtualización local con VirtualBox
  • Despliegue de máquinas virtuales en VirtualBox
  • Acceso remoto seguro vía SSH

🛡️ Seguridad y Hardening

  • Implementación de Firewalls
  • Auditoría de sistemas
