Enfoque en Seguridad

Esta evaluación se enfoca específicamente en seguridad de sistemas operativos, aplicando conceptos vistos en las clases 15, 16 y 17. Se evaluarán mecanismos de protección, control de acceso y hardening.

Contenido Teórico (40%)

  • Mecanismos de protección:
    • SELinux (Security-Enhanced Linux)
    • AppArmor
    • UAC (User Account Control) en Windows
    • Firewalls básicos (iptables, Windows Firewall)
  • Control de acceso:
    • DAC (Discretionary Access Control)
    • MAC (Mandatory Access Control)
    • RBAC (Role-Based Access Control)
  • Amenazas y vulnerabilidades:
    • Buffer overflow
    • Rootkits y malware
    • Escalación de privilegios

Contenido Práctico (60%)

  • Permisos avanzados Linux:
    • chmod, chown - Permisos básicos
    • SUID, SGID, Sticky bit
    • ACLs (Access Control Lists) con setfacl/getfacl
    • Atributos extendidos (chattr, lsattr)
  • Gestión de usuarios y grupos:
    • useradd, usermod, userdel
    • groupadd, groupmod
    • Archivos /etc/passwd, /etc/shadow, /etc/group
  • Hardening y auditoría:
    • Desactivar servicios innecesarios
    • Configuración de SSH seguro
    • Auditoría con auditd
    • Scripts de verificación de seguridad

Información General de Evaluaciones

📚 Metodología de Evaluación

Este curso utiliza una metodología teórico-práctica 40/60, donde el 40% evalúa comprensión conceptual y el 60% evalúa aplicación práctica en entornos reales Linux y Windows.

No hay exámenes de memorización. Los exámenes incluyen análisis de escenarios prácticos con comandos reales, resolución de problemas y desarrollo de soluciones.

📋 Políticas de Evaluación

  • Entregas: Se realizarán por la plataforma institucional antes de la fecha y hora límite indicada.
  • Formato: Los informes deben seguir la estructura académica formal (portada, índice, desarrollo, conclusiones, referencias).
  • Originalidad: Todos los trabajos serán verificados con herramientas de detección de plagio.
  • Trabajo colaborativo: Solo cuando se indique explícitamente. Los exámenes son estrictamente individuales.
  • Recuperaciones: Según reglamento institucional. Revisar Acta de Concertación.

⚠️ Recomendaciones para el Éxito

  • Practica semanalmente en tu máquina virtual Ubuntu Server.
  • Documenta todo lo que haces con capturas de pantalla.
  • Revisa las rúbricas antes de entregar para autoevaluarte.
  • Participa en clase y resuelve tus dudas inmediatamente.
  • Usa el glosario para familiarizarte con la terminología técnica.
