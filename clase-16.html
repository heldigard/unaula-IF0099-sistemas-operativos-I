Teoría: Active Directory

¿Qué es Active Directory?

Active Directory (AD) es el servicio de directorio de Microsoft Windows para redes empresariales. Centraliza la administración de usuarios, computadoras, políticas y recursos.

Funciones Principales

  • Autenticación centralizada
  • Authorization (permisos)
  • Gestión de políticas (GPOs)
  • Directorio de recursos (impresoras, compartidos)
  • Administración centralizada

Beneficios

  • Single Sign-On (SSO)
  • Administración centralizada
  • Políticas de grupo consistentes
  • Seguridad granular
  • Escalabilidad empresarial

Conceptos Fundamentales

Dominio

  • Unidad lógica de administración
  • Agrupa usuarios, computadoras y recursos
  • Tiene una base de datos AD replicada
  • Ejemplo: empresa.local

Controlador de Dominio (DC)

  • Servidor con AD DS instalado
  • Almacena y replica la base de datos AD
  • Procesa autenticaciones
  • Aplica GPOs

Organizational Unit (OU)

  • Contenedor para organizar objetos
  • Permite delegar administración
  • Puede aplicar GPOs específicos
  • Estructura jerárquica

Grupo

  • Agrupa usuarios o computadoras
  • Simplifica asignación de permisos
  • Grupos de seguridad y distribución

Objeto

  • Entidad en AD (usuario, computadora, impresora, etc.)
  • Tiene atributos únicos
  • Identificado por Distinguished Name (DN)

Protocolos AD

LDAP (Lightweight Directory Access Protocol)

  • Protocolo para consultar y modificar AD
  • Puerto 389 (LDAP), 636 (LDAPS)
  • Estructura jerárquica
  • Formato: ldap://servidor:puerto/DN

Kerberos

  • Protocolo de autenticación
  • Puerto 88
  • Autenticación mutua
  • Tickets (TGT, Service Tickets)
  • SSO (Single Sign-On)

DNS

  • Requerido para AD
  • Resuelve nombres de dominio
  • SRV records para localizar DCs
  • Integrado con AD DNS

Group Policy Objects (GPOs)

  • Configuraciones centralizadas
  • Se aplican a OUs, dominios o sitios
  • Controlan configuraciones de usuarios y computadoras
  • Ejemplos: scripts de inicio,壁纸, permisos, etc.

Instalar Active Directory Domain Services

Requisitos previos:
  • VM con Windows Server 2022
  • IP estática configurada
  • Nombre de servidor adecuado
  • Usuario con privilegios de Administrador

Paso 1: Configurar IP estática

# Ver configuración actual
Get-NetIPAddress

# Configurar IP estática (ajustar según tu red)
New-NetIPAddress -IPAddress 192.168.1.10 `
    -DefaultGateway 192.168.1.1 `
    -PrefixLength 24 `
    -InterfaceAlias "Ethernet"

# Configurar DNS (apuntar a sí mismo)
Set-DnsClientServerAddress -InterfaceAlias "Ethernet" `
    -ServerAddresses 192.168.1.10

Paso 2: Cambiar nombre del servidor

# Cambiar nombre del servidor
Rename-Computer -NewName "DC01" -Restart

# Después de reiniciar, continuar con instalación de AD

Paso 3: Instalar AD DS con PowerShell

# Instalar AD DS y herramientas de administración
Install-WindowsFeature -Name AD-Domain-Services `
    -IncludeManagementTools `
    -IncludeAllSubFeature

# Verificar instalación
Get-WindowsFeature -Name AD-Domain-Services
Nota: También puedes instalar con Server Manager:
  1. Abrir Server Manager
  2. Manage → Add Roles and Features
  3. Seleccionar "Active Directory Domain Services"
  4. Instalar características requeridas

Promover a Controlador de Dominio

Opción 1: Usar PowerShell (Recomendado)

# Importar módulo
Import-Module ADDSDeployment

# Promover servidor a Controlador de Dominio
# Crear nuevo bosque
Install-ADDSForest `
    -DomainName "empresa.local" `
    -DomainNetbiosName "EMPRESA" `
    -ForestMode "WinThreshold" `
    -DomainMode "WinThreshold" `
    -InstallDns:$true `
    -SafeModeAdministratorPassword (ConvertTo-SecureString "P@ssw0rd123!" -AsPlainText -Force) `
    -Force:$true

# El servidor se reiniciará automáticamente

Opción 2: Usar Configuration Wizard

  1. Abrir Server Manager
  2. Hacer clic en el ícono de notificación (flag)
  3. "Promote this server to a domain controller"
  4. Configurar:
    • Deployment: Add a new forest
    • Domain name: empresa.local
    • Forest/Domain mode: Windows Server 2016 o superior
    • DNS options: Marcar "Install DNS"
    • Password: DSRM password (recuperación)
  5. Hacer clic en "Install"
  6. El servidor se reiniciará

Verificar instalación

# Después de reiniciar, verificar
Get-Service NTDS
Get-Service DNS

# Ver información del dominio
Get-ADDomain

# Ver controladores de dominio
Get-ADDomainController
DC Promovido Exitosamente:
  • Servicio AD DS (NTDS) corriendo
  • Servicio DNS instalado y configurado
  • Cuenta de Administrador del dominio creada
  • Base de datos AD creada

Crear OUs, Usuarios y Grupos

Paso 1: Abrir Active Directory Users and Computers

# Desde PowerShell
dsa.msc

# O desde Server Manager
Tools → Active Directory Users and Computers

Paso 2: Crear Organizational Units

# Con PowerShell
New-ADOrganizationalUnit -Name "Usuarios" -Path "DC=empresa,DC=local"
New-ADOrganizationalUnit -Name "Grupos" -Path "DC=empresa,DC=local"
New-ADOrganizationalUnit -Name "Computadoras" -Path "DC=empresa,DC=local"
New-ADOrganizationalUnit -Name "Servidores" -Path "DC=empresa,DC=local"

O con GUI:

  1. Hacer clic derecho en empresa.local
  2. New → Organizational Unit
  3. Ingresar nombre (ej: "Usuarios")
  4. Repetir para otras OUs

Paso 3: Crear Usuarios

# Crear usuario
New-ADUser -Name "Juan Pérez" `
    -GivenName "Juan" `
    -Surname "Pérez" `
    -SamAccountName "j.perez" `
    -UserPrincipalName "j.perez@empresa.local" `
    -Path "OU=Usuarios,DC=empresa,DC=local" `
    -AccountPassword (ConvertTo-SecureString "P@ssw0rd123!" -AsPlainText -Force) `
    -Enabled $true

# Crear más usuarios
New-ADUser -Name "María García" `
    -GivenName "María" `
    -Surname "García" `
    -SamAccountName "m.garcia" `
    -UserPrincipalName "m.garcia@empresa.local" `
    -Path "OU=Usuarios,DC=empresa,DC=local" `
    -AccountPassword (ConvertTo-SecureString "P@ssw0rd123!" -AsPlainText -Force) `
    -Enabled $true

# Ver usuarios creados
Get-ADUser -Filter * -SearchBase "OU=Usuarios,DC=empresa,DC=local"

O con GUI:

  1. Hacer clic derecho en OU "Usuarios"
  2. New → User
  3. Ingresar:
    • First name: Juan
    • Last name: Pérez
    • User logon name: j.perez
  4. Next → Password → Next → Finish

Paso 4: Crear Grupos

# Crear grupos
New-ADGroup -Name "Ventas" `
    -GroupScope Global `
    -Path "OU=Grupos,DC=empresa,DC=local"

New-ADGroup -Name "IT" `
    -GroupScope Global `
    -Path "OU=Grupos,DC=empresa,DC=local"

# Ver grupos
Get-ADGroup -Filter * -SearchBase "OU=Grupos,DC=empresa,DC=local"

Paso 5: Agregar usuarios a grupos

# Agregar usuario a grupo
Add-ADGroupMember -Identity "Ventas" -Members "j.perez"
Add-ADGroupMember -Identity "IT" -Members "m.garcia"

# Ver miembros de un grupo
Get-ADGroupMember -Identity "Ventas"

Unir Cliente al Dominio

Requisitos:
  • VM o computadora con Windows 10/11
  • Conectividad de red con el DC
  • DNS configurado para apuntar al DC

Paso 1: Configurar DNS del cliente

# En el cliente, configurar DNS
# Windows Key + R → ncpa.cpl → Propiedades de red → IPv4 → DNS
# Servidor DNS: 192.168.1.10 (IP del DC)

# O con PowerShell
Set-DnsClientServerAddress -InterfaceAlias "Ethernet" `
    -ServerAddresses 192.168.1.10

Paso 2: Verificar conectividad

# Hacer ping al DC
ping 192.168.1.10

# Verificar resolución de nombres
ping dc01.empresa.local

Paso 3: Unir al dominio

# Con PowerShell (como administrador)
Add-Computer -DomainName "empresa.local" `
    -Credential "empresa.local\administrator" `
    -Restart

# O con GUI
# Windows Key + R → sysdm.cpl → Cambio → Dominio
# Ingresar: empresa.local
# Credenciales: Administrator del dominio
# Reiniciar

Paso 4: Verificar unión al dominio

# Después de reiniciar, verificar
Get-ADComputer -Filter "Name -like 'PC01'"

# O en System Properties
# Windows Key + R → sysdm.cpl → Nombre del equipo
# Debe mostrar: Dominio: empresa.local

Paso 5: Iniciar sesión con usuario de dominio

  1. En la pantalla de login, hacer clic en "Other user"
  2. Usuario: EMPRESA\j.perez
  3. Contraseña: [la que configuraste]
  4. Deberías iniciar sesión exitosamente
Verificación exitosa:
  • Usuario de dominio puede iniciar sesión
  • Comprobación con: whoami muestra empresa.local\j.perez
  • Comprobación con: whoami /groups muestra grupos

Actividad Práctica

Actividad: Implementación de Active Directory

Objetivo

Implementar un dominio Active Directory básico con usuarios, grupos y una máquina cliente.

Requisitos

  1. Instalar AD DS en Windows Server
  2. Promover servidor a Controlador de Dominio
  3. Crear al menos 2 OUs (Usuarios, Grupos)
  4. Crear al menos 2 usuarios
  5. Crear al menos 1 grupo
  6. Unir un cliente Windows al dominio
  7. Verificar login de usuario de dominio

Evidencias a Entregar

  • Captura de Get-ADDomain (información del dominio)
  • Captura de las OUs creadas en ADUC
  • Captura de los usuarios creados
  • Captura de los grupos creados
  • Captura de PC cliente en "Computers" del dominio
  • Captura de whoami desde el cliente
