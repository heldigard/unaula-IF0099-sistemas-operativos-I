1. Configuración de la Infraestructura Híbrida

En esta fase, tus dos máquinas virtuales deben trabajar como un único sistema corporativo (UCS).

Requisito de Red: Ambas VMs deben tener IPs estáticas en el mismo segmento y poder hacerse ping mutuamente.

Checklist de Conectividad

  • Linux (Ubuntu Server): 192.168.1.X (ejemplo)
  • Windows (10/11/Server): 192.168.1.Y
  • Firewalls configurados para permitir tráfico en puertos 80, 443, 8080 y ICMP (Ping).

2. Persistencia y Almacenamiento Avanzado

Debes demostrar que el sistema es capaz de manejar fallos de disco y mantener la información persistente.

Tareas Técnicas:

  1. RAID 1 (Espejo): Configurar un arreglo RAID 1 en Linux con dos discos virtuales adicionales de 1GB cada uno.
  2. Punto de Montaje: Montar el RAID en /var/www/html/datos_empresa.
  3. Persistencia fstab: Configurar el UUID del RAID en /etc/fstab para que se monte automáticamente al reiniciar.
# Ejemplo de línea en /etc/fstab
UUID=your-uuid-here  /var/www/html/datos_empresa  ext4  defaults,noatime  0  2

3. Servicios Web (Apache & IIS)

UCS debe servir contenido desde ambas plataformas simultáneamente.

Escenario: El cliente accede al portal principal en Linux y a una aplicación administrativa en Windows.

Configuración Apache (Linux)

  • Virtual Host: Configurar ucs.local apuntando a tu contenido.
  • HTTPS: Generar certificado auto-firmado y habilitar el módulo SSL.

Configuración IIS (Windows)

  • Puerto 8080: Cambiar el binding para que IIS no choque con otros servicios si fuera necesario.
  • Application Pool: Crear un pool dedicado llamado "UCS_Pool" con identidad de servicio específica.

4. Dashboard de Salud (Script de Integración)

Crea un script final en Bash (check_ucs.sh) que valide todo el sistema en un segundo:

#!/bin/bash
echo "--- UCS HEALTH CHECK ---"
# Validar si Apache corre
systemctl is-active --quiet apache2 && echo "[OK] Apache Funcionando" || echo "[FAIL] Apache Caído"
# Validar si el RAID está montado
mountpoint -q /var/www/html/datos_empresa && echo "[OK] RAID Persistente" || echo "[FAIL] RAID No Montado"
# Validar visibilidad de Windows
ping -c 1 192.168.1.Y > /dev/null && echo "[OK] Nodo Windows Visible" || echo "[FAIL] Nodo Windows Inaccesible"
